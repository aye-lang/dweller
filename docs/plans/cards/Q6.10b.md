# Q6.10b: WPT `html/semantics/forms` toward its target

- goal: the Target column of `docs/conformance.md` for `html/semantics/forms`: 82 (4439 of 5413). Q6.10 left it at 3441/5413 (63.6%); 3521/5413 (65.0%) measured on the tree merged with the wave branch at the start of this card. The largest one-cause cluster first.
- order: taken before Q6.6b. The integrator's list says "the largest one-cause cluster first"; the clusters left in `css/cascade-variables` are at most 36 subtests each (see Q6.6b when it is written), the ones here 60 to 190.
- design (clusters in the order done; subtests are of the area's 5413):
  - `input type=color` took `#rrggbb` only (`color.window.js` 182, `color.html` 12). Its value is now a CSS colour run through the sanitization algorithm of the colour state: parsed by the CSS colour parser, opaque black when it does not parse, written as `#rrggbb`, or as `color(srgb ...)` / `color(display-p3 ...)` when the `alpha` or `colorspace` attributes ask for it (`css/input-color-text.aye`, `parsed-input-color.aye`, `eight-bit-channels.aye`, `write-input-color.aye`, `write-hex-color.aye`; `engine/color-input-value.aye`, `color-input-source.aye`; `colorSpace` and `alpha` in `reflection-table.js`). A value that is not dirty is sanitized from the `value` attribute at each read, so adding `alpha` recovers an alpha the attribute had. 3521 -> 3710, then 3716 with six decimals in the channels.
  - the form submission encoding tests (`urlencoded2`, `text-plain`, `multipart-formdata`: 186) could not pass here whatever the browser did:
    - they post to `/FileAPI/file/resources/echo-content-escaped.py`. That directory was not in the sparse WPT checkout, the runner's static server had no `do_POST`, the handler shim gave a handler no method and no body, and `Headers.set` of the shim raised for every handler that returns headers (it called the two-argument `append` with one). **Tooling changed:** `browser/tools/wpt.py` (`EXTRA_DIRS` gains `FileAPI/file/resources`, `do_POST`) and `browser/tools/wpt_handler.py` (`method`, `body`, the `set` fix). The `set` fix can change results of other areas that use Python handlers with headers; not measured.
    - a script-inserted `iframe` with no `src` fired its first `load` later, from the frame loader, so a test that sets `onload` after `form.submit()` saw the blank document. The load is now announced when the element is inserted (`frameDiscover` in `prelude.aye`, `engine/ak-blank-frame-loaded.aye`, `take-announced.aye`); the frame itself is still made lazily, and its first load is then not fired a second time. (Making the frame at insertion hung `form-double-submit-requestsubmit`; that version was dropped.)
    - a frame whose element left the document still answered to its name: `namedFrame` skips it (`frames.aye`), so a second test's `iframe` of the same name is the target.
    - `form.submit()` fired no `formdata` event. `FormDataEvent` exists; constructing a `FormData` from a form fires `formdata` at it, guarded against re-entry; `form.submit()` constructs the entry list, stops when the form left the document, and submits the list the listeners left (`ak.submitEntries`/`submitEntry`, `engine/ak-submit-entries.aye`, `ak-submit-entry.aye`, `take-submit-entries.aye`, `drop-entries.aye`; `Script.submit_form`, `submit_entries`). A later default-action submission of the same form drops that list and reads the controls again.
    The three files: 0/186 -> 136/186; with `FormDataEvent`, `constructing-form-data-set`, `form-target-iframe` and others, 3716 -> 3868.
- decisions taken without asking (plan defaults):

  - `formdata` fires for `form.submit()` and `new FormData(form)`. A submission by a button, by `requestSubmit()` or by Enter is built natively and fires no `formdata` yet (Left).
  - a `File` in the entry list is submitted by name with no content.

By the colour state's sanitization `red` is `#ff0000`; the fixture now asserts that (`color name`) and keeps the fallback check with a string that is not a colour. `forms_types.tree` changes in two lines: the echoed script text and the result log, which gains `color name`.
