# P11.13: WebGL 2 extensions

- goal: `getSupportedExtensions` and `getExtension` for the WebGL 2 set of docs/webgl.md §3, each enabled with `glRequestExtensionANGLE` only when ANGLE lists it in `GL_REQUESTABLE_EXTENSIONS_ANGLE` (or already has it on), with `compressedTexImage2D`/`3D`, `compressedTexSubImage2D`/`3D` and the block size checks of each compressed format spec; every name three.js r170 (`WebGLExtensions.js`, `WebGLCapabilities.js`) probes gives the right object or `null`.
- design:
  - The JS lives in `browser/engine/webgl2-ext.js` (embedded by `webgl2-ext-prelude.aye`, run right after `WEBGL2_REST_PRELUDE` in `script.aye`). It replaces the prelude's `getExtension`/`getSupportedExtensions` (removed from `webgl_prelude.aye`) and wraps `getParameter` (`MAX_TEXTURE_MAX_ANISOTROPY_EXT`, `UNMASKED_VENDOR/RENDERER_WEBGL`, `COMPRESSED_TEXTURE_FORMATS`), `getShaderParameter`/`getProgramParameter` (`COMPLETION_STATUS_KHR`), and adds `getTexParameter` (needed to read anisotropy back; all WebGL 2 texture pnames).
  - A table maps each WebGL name to its ANGLE extensions (S3TC needs `EXT_texture_compression_dxt1` + `ANGLE_texture_compression_dxt3`/`dxt5`, ETC `ANGLE_compressed_texture_etc`, ASTC `KHR_texture_compression_astc_ldr`), its constants and, for compressed formats, `[format, blockW, blockH, blockBytes]`. `getExtension` builds one plain object per name per context (cached in `_exts`, null cached too); enabling a compressed extension registers its formats in `_blocks`, which drives `COMPRESSED_TEXTURE_FORMATS` and the size check (`ceil(w/bw)*ceil(h/bh)*bytes*depth`, else `INVALID_VALUE`; a format of no enabled extension is `INVALID_ENUM`).
  - Compressed uploads take a view with `srcOffset`/`srcLengthOverride` (in elements), or `imageSize, offset` with a `PIXEL_UNPACK_BUFFER` bound (the other mix is `INVALID_OPERATION`).
  - `WEBGL_debug_renderer_info` gives the generic strings `Dweller` / `Dweller WebGL`.
  - Natives: `enableExtension` (`enable-extension.aye`, used by `webglQuery` op 2; `extension-listed.aye` matches a name in a space-separated list), `webglTexParameter` (`webgl-tex-parameter.aye`), `webglCompressed` (`webgl-compressed.aye`). Five `gl.aye` entry points.
- files: `browser/engine/webgl2-ext.js`, `webgl2-ext-prelude.aye`, `enable-extension.aye`, `extension-listed.aye`, `webgl-tex-parameter.aye`, `webgl-compressed.aye`, wiring in `webgl_api.aye`, `webgl_prelude.aye`, `script.aye`, `browser/gpu/gl.aye`, `browser/tests/webgl/extensions.html` + `.txt`, `tests/browser.rs` (`webgl_extensions`).
- reference: `third_party/blink/renderer/modules/webgl/` (`webgl_rendering_context_base.cc` compressed checks, one file per extension; algorithm only), ANGLE `include/GLES2/gl2ext_angle.h`, the Khronos WebGL extension registry.
- verify: `cargo test --release --test browser -- webgl_extensions` → 0; `cargo test --release --test browser -- gpu webgl screenshot_` → 0 (15 passed, no golden changed).
- status: done 2026-10-17. On SwiftShader the supported list is `EXT_color_buffer_float EXT_color_buffer_half_float EXT_float_blend EXT_texture_filter_anisotropic OES_texture_float_linear WEBGL_debug_renderer_info WEBGL_compressed_texture_s3tc WEBGL_compressed_texture_s3tc_srgb WEBGL_compressed_texture_etc WEBGL_compressed_texture_astc EXT_texture_compression_bptc EXT_texture_compression_rgtc`. Test `webgl_extensions`: same object twice, `NOPE` null, the three.js probes, render to an RGBA16F FBO read back as floats (0.25, 2.5, -1, 1), anisotropy 1 → 2 read back, a DXT1 block uploaded (offset view and sub-image) and sampled red, short data `INVALID_VALUE`, unknown format `INVALID_ENUM`.
- left:
  - `WEBGL_lose_context` is not exposed: `loseContext`/`restoreContext` need the lost-context path of P11.15 (exposing no-op methods would hang pages waiting for `webglcontextrestored`).
  - `KHR_parallel_shader_compile` and `EXT_texture_norm16` are in the table but SwiftShader's ANGLE does not offer them, so they are untested here.
  - Compressed uploads do not check the dimension rules (multiple of 4 at level 0, `texStorage` immutable formats); ANGLE's WebGL validation does.
  - `getTexParameter` does not reject pnames by texture target beyond what GL does.
