## Slice 1: transitions of sizes and box edges

- causes, three:
  - `getComputedStyle(e).padding` (and `margin`, `border-width`, ...) wrote the cascaded longhands, not the values of a running transition; the longhand read was right.
  - with `transition-behavior: allow-discrete`, a length property did not start a transition between values that cannot interpolate (`auto` and `40px`), and the first half of a discrete step read the internal `initial` instead of the initial value.
  - a transition between a length and a percentage did not run (`10px` to `100%`); it is `calc()`.
- design:
  - `animation.animatedCopy`: the element's values with those of its running transitions; `akComputedStyle` reads every shorthand and longhand from that copy (freed by `freeValues`).
  - `allowsDiscrete` also holds for the length properties (`PKind.Length`, `LengthNonNeg`). For every property it does not: `css/css-animations` loses 26 (`display-interpolation`, `transition-properties-not-animatable`), measured in Q6.3. `flipped` resolves an internal `initial` to the property's initial value.
  - `mixLengths`: `interpolate` falls back to (px, percent) pairs when the kinds differ; the result is `Px`, `Percent` or `Calc`.
  - `progressAt`: a transition is active at its start time (`local < 0`, not `<= 0`), so `step-start` shows the end value in the first frame (`css/css-transitions/allow-discrete-auto-inset.html`).
  - `writeComputedSides` frees the four side strings (a leak that the new fixture showed under `--leak-check`).
- references: https://drafts.csswg.org/css-transitions-2/#transition-behavior-property , https://drafts.csswg.org/css-values-4/#combine-mixed , https://drafts.csswg.org/css-transitions-1/#application . No Chromium file read.
- files: `browser/animation/allows-discrete.aye`, `interpolate.aye`, `value-at.aye`, new `animated-copy.aye`, `flipped.aye`, `mix-lengths.aye`, `length-pair.aye`; `browser/engine/window_api.aye` (`akComputedStyle`: six lines), new `free-values.aye`; `browser/css/write-computed-sides.aye`; new fixture `browser/tests/jsdom/transition_size_values.html` and `.tree` (golden new: `15px 15px`, `auto` then `40px`, `25%`); `browser/tools/conformance/css_box-sizing.json`.
