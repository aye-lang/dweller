#### P4.75w: reuse computed values across elements; sheet key without a document walk

- goal: cut mistral's `script_layout` (3.8–4.0 s over 8143 forced layouts after P4.75v; target ≤ 2.6 s) with (1) Blink's `MatchedPropertiesCache`: elements with the same matched rules and the same inherited parent values share computed values instead of running value computation again; (2) the style-sheet source key kept per document and computed again only when a sheet source changes; (3) if time is left, incremental relayout next to floats. github and react must not get slower; identical output.
- design (Blink's algorithms, no code copied):
  - matched key: `offerRule` appends (sheet index, cascade level, rule index, specificity) of every rule offered for the element to `Styles.matched` (`MatchedCache`). The sheet index is 0 for the UA sheet, 1 for quirks, 2 + i for the scope i of `Computer.scopes`; the cache is cleared when `swapSheets` replaces the author sheet in place.
  - lookup (`matchedValues`, in `Computer.compute`): a 256-slot direct-mapped table, hashed from the key words, the inherited custom-property level (pointer), the root font size, the root line height and the viewport. A hit needs equal words, level, context and equal inherited values of the parent (`sameInherited`: the 33 inherited properties, to the bit); it copies the cached values and reuses the cached custom-property level (so the children of a hit hit too).
  - not cached (Blink's `IsCacheable` rules): the root element; a `style` attribute or presentational hints (`writeHints`); `inherit` on a non-inherited property; container units (also after `var()` substitution); a parent that centres its children (`<center>`, `align`); more than 48 matched rules.
  - the entry holds one reference to its interned values (`Styles.shared`), so they cannot be freed and reused; a hit takes another reference by the kept hash (`holdShared`) without hashing or comparing the values again. A miss interns once (`internWith`) and keeps the hash; an evicted entry releases by its hash (`releaseWith`). The parent's inherited values are copied into the entry.
  - sheet key: `Document.sheet_version` counts DOM changes that can change a sheet source (`noteSheetChange` / `touchesSheets`): an inserted or removed node that is, or is inside, a `style`/`link`/`base` element, or whose subtree has one or a shadow host; attributes of those elements; text data inside them. `treesSourceKey` keeps the walk of the document and its shadow trees in `Document.sheet_key_cache` while `sheet_version` and the number of shadow roots stay the same; the CSSOM generation and adopted sheets are mixed in on every call as before. Blink: `StyleEngine::AddStyleSheetCandidateNode`, `MarkTreeScopeDirty`, `UpdateActiveStyle`.
