# P10.51g: invalidation sets narrow state restyles

- goal: (1) per-key invalidation sets in `RestyleDeps`: a pointer/focus state change restyles only the chain elements whose own compound can match and the descendants that match the subject compound; (2) hover in iframes restyles locally in the frame; (3) `Transitions.kept` stops growing. P10.51f's "left" list.
- design:
  - `RestyleDeps.states` (`StateUse`, built by `addStateUses` over author, UA, quirks and scoped sheets): for each `:hover`/`:active`/`:focus`/`:focus-visible`/`:focus-within` directly in a compound, the compound's feature (`own`: id > class > attribute > type, `compoundFeature`; 0 any) and, when the compound is left of the subject, the subject compound's feature (`target`); `around` (use the old deep path) when it sits in a functional pseudo-class, before `+`/`~`, or in a `::slotted`/`::part` selector. Features are hashes of lower-cased names (`featureKey`), matched by `hasFeature` (tag, attribute names, id, class tokens): conservative.
  - `css.FOCUS_WITHIN_CHANGED` (`what` 5; `nameKey` clear of 0..5): `noteLeftChain` notes the focus target with `FOCUS_CHANGED` and its ancestors with `FOCUS_WITHIN_CHANGED` (`chainChange`), so `:focus`/`:focus-visible` uses do not make every ancestor match. `simpleKeys` gives `:focus-within` both keys.
  - `noteLeftChain` skips chain elements no use can match (`stateMatters`; not when the sheet uses `:has()`). `restyleRoots` asks `stateRoots` first for a state change without a `:has()` anchor: a subject use roots the element (shallow), a descendant use roots each descendant with the target feature (`addMatchingDescendants`, shallow), target 0 roots the subtree; an `around` use falls back to the generic path.
  - `restyleSubtrees` styles for context only the ancestors not shared with the previous root's chain (`rebuildChain`), not all of them when the parents differ.
