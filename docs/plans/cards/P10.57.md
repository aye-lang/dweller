# P10.57: url: the WHATWG URL parser

- goal: WPT `url` from 48.8% to the 80% threshold; URL parsing sits under every link, fetch, relative path and history entry.
- design: the basic URL parser of the URL Standard as a state machine, one file per state (`*-state.aye`), over a `Parser` record (`parser.aye`: scheme, userinfo, host, port, path segments as spans into one byte buffer, query, fragment, state override). It works on UTF-8 bytes: every byte ≥ 0x80 is in every percent-encode set, so byte-wise encoding equals the spec's per-code-point encoding. `serializeUrl` builds the existing `Url` (href plus slices), so no caller changed: `parse`, `resolve`, `resolveIn` in `url.aye` now call `basicParse`. Hosts: `parseHost` (IPv6 parser and serializer, IPv4 number and address parser, ends-in-a-number, opaque host, forbidden host and domain code points). `uts46ToAscii` is a stub (ASCII lower-casing) until the IDNA step lands. The state override (`Parser.override`) is in place for the setters but not yet wired to the `URL` class.
- files: `browser/url/` (new: `parser.aye`, `new-parser.aye`, `free-parser.aye`, `basic-parse.aye`, `clean-input.aye`, `run-parser.aye`, `run-state.aye`, 19 `*-state.aye` and their helpers, `parse-host.aye`, `parse-ipv4*.aye`, `parse-ipv6.aye`, `ipv6-*.aye`, `append-ipv4.aye`, `append-ipv6.aye`, `serialize-url.aye`, `append-authority.aye`, `append-path.aye`, `encode-set.aye`, `percent-encode.aye`, `domain-to-ascii.aye`, `uts46-to-ascii.aye`; rewritten `encode-query.aye`; `url.aye` loses the old ad-hoc parser).
- reference: https://url.spec.whatwg.org/#concept-basic-url-parser (no code ported, so no license note).
- verify: `conformance.py run url` before/after; `conformance.py table`; `cargo test --release --test browser -- jsdom_fixtures style_fixtures layout_fixtures errors agent_ net` exit 0; `cargo test --release --test browser -- aye_unit_tests` exit 0; `conformance.py run fetch/api xhr html/semantics/forms dom/nodes` with no file lower than on `origin/main`'s binary; `check_taste.py`, `check_layers.py` clean.
