# Q3.10c: `<link>` elements fire `load` and `error`

- goal: `<link rel=stylesheet>` fires `load` once its sheet is fetched, `error` for a network error, a non-2xx status, a nosniff/MIME refusal, a CORS failure or a CSP refusal; `rel=preload` (with `as`), `modulepreload` and `prefetch` fire them too; `rel=icon` and the others none. Inserted links and changes of `href`/`rel`/`crossorigin`/`as`/`referrerpolicy` refire. `link.sheet` is null for an inserted link until its load, and for a failed one. `onload`/`onerror` attributes work. WPT `fetch/nosniff/stylesheet.html` (0/18, timeout) passes.
- source: Q3.10's Left.
- design:
  - Sheets are still collected per style pass, not per element, so the events come from a separate request per link, made in a task, like an image's. The prelude (`linkUpdate`, `linkDiscover`, `linkForget`) queues one `ak.imageTask` for a connected link of this document whose `rel` has `stylesheet`, `preload`, `modulepreload` or `prefetch` and whose `href` is not empty. It runs at the parse (the links of the document), for an inserted subtree (mutation kind 3) and for `href`, `rel`, `crossorigin`, `as` and `referrerpolicy` changes of a connected link. A removal forgets the request, so inserting again refires. A newer request makes the older task do nothing. The task delays the document's `load` event (as an image's does), so a parsed link fires before `window.onload`.
  - No blocking fetch on the loop. A stylesheet link does not fetch at all: `linkedSheet` (the style pass) records its result per URL and CORS flag (`engine/sheet-results.aye`, a ring of 64), and the task reads it (`ak.linkLoad(link, last)`, `engine/link-outcome.aye`: 0 no event, 1 load, 2 error, 3 CSP refusal, 4 not known yet). So a sheet is fetched once, also a `no-store` one. If the pass has not run when the task does, the task forces it once (`getComputedStyle(document.documentElement)`, the same single fetch), then asks again after 50 ms up to twice, and the last ask fetches itself (`link-fetched.aye`) for a link no pass reads (media that does not match, a disabled sheet).
  - `preload`, `modulepreload` and `prefetch` start a background load (`ak.linkStart`, `link-start.aye`, `net.startLoadAs`), and the task waits for it through `imageTask`'s load id, as an image does; the request that follows reads the finished load. `linkRelationOf`, `linkRequest` (the request per rel; `preload-kind.aye` maps `as`) and `linkHrefUrl` are shared. A status outside 200-299 is an error; a fetched sheet with such a status is not applied (`linkedSheet`).
  - CSP: Q3.8's `reportStyleRefusal` already fires `error` at a blocked link (and style). `linkOutcome` returns 3 for a blocked sheet so the prelude fires nothing again and `sheet` stays null.
  - `link.sheet` (prelude getter): null while a link inserted after the parse has no result, and after an error or refusal. The links of the parsed document keep their sheet at once, since scripts that run during the parse see them loaded in a browser, and `styleSheets` lists are unchanged.

Dweller takes: one task per request that fires the event, delayed document load, refire on attribute change and re-insertion, and the as-to-destination table.

## Status: done, 2026-11-09

Left:
- A stylesheet link's `load` comes from the style pass's result for its URL (keyed by URL and CORS flag, not by element): two links of one URL share a result.
- The window harness (`--events frame`) can take its snapshot before a chain of link events in tab mode has run; `link_events_in_renderer` waits 150 frames.
- `preload`/`prefetch` fetch the resource only to fire the event (the cache then serves a later use); `media`, `type` and `imagesrcset` of preloads are ignored, `integrity` is not checked, and `fetchpriority`/`nonce` have no effect. `prefetch` fetches at once, not when idle.
- A sheet's `@import` failing does not fire `error` on the link (the spec fires `load` anyway); a MIME refusal that is not nosniff (a cross-origin `text/html` sheet in standards mode) is accepted.
- `rel=stylesheet` in a shadow tree or a detached template fires nothing; `<link>` in an `<svg>` or `<style>`-less XML document is not handled.
- `link.disabled`/`alternate` handling and the `title`-based preferred sheet set are unchanged: an alternate sheet gets its event, as in Chromium, but is not applied.
