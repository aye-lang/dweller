# Q4.25d: a renderer runs a load's scripts and its timers as bounded tasks

- goal: with `DWELLER_PROCESS=site` the renderer no longer runs all the scripts of a load in one task (bbc: 4.1 s), so an input is handled between them.
- source: `docs/plans/cards/Q4.25.md` (d), row Q4.25d of `foundations.md`.
- design:
  - the load: done by Q2.16a's first slice (`docs/plans/cards/Q2.16a.md`): `advanceStaged` → `stepStaged` runs `engine.stepPageScripts` (one script a step, as the window's `stepPageScripts`) for at most 50 ms a turn of the renderer's loop, then goes back to the loop, which reads the socket: a wheel, click or key is dispatched between two scripts, and `paintWaits` lets the frame for that input out while the scripts run.
  - this card adds the same bound to timer tasks: `runTimers` passes `engine.runDueTimersUntil` a deadline of 50 ms (`TIMER_TASK_MS`, the window's `TASK_BUDGET_MS`); before, a turn ran every due timer (up to the engine's task limit) with no deadline. The timers left are due at once, so `timerWait` is 0 and the next turn runs them after the socket was read.
  - one script or one timer callback is still one task: nothing interrupts it.
- files: `browser/renderer/run-timers.aye`; `tests/browser/window_renderer_perf.rs` (new `window_renderer_perf_input_between_scripts`). The staged load's files are in Q2.16a's card.
- verify (2026-11-16, Linux x86_64, 4 cores; proxy variables unset for the tests):
  - `aye check browser`: exit 0. `aye test browser`: 312 passed, 0 failed. `check_taste.py`, `check_layers.py`, `gen_property_ids.py --check`: exit 0. `browser/build.sh`: exit 0.
  - `cargo test --release --test browser`: 271 passed, 0 failed (296 s).
  - new `window_renderer_perf_input_between_scripts` (`perf/staged_scripts.html`: eight inline scripts of 100 ms; a wheel sent once the first frame is shown): 12 `scripts` records follow the wheel's `input_to_frame` record, the longest `scripts` record is 114 ms.
  - `DWELLER_PROCESS=tab window_perf.py scroll .../perf/staged_scripts.html --frames 5 --step "renderer:loaded wheel:-3 renderer:input"`, 3 runs: `longest_task_ms` (the longest `scripts`, `timers` or `ui_raf` record) 1079, 1078, 1063 ms with the binary from before this lane (main at a284b98) → 100, 100, 100 ms; the renderer's longest loop turn (`r_task`, Q4.25c) 149, 101, 101 ms.
