- goal: react on `target/sites-old-20261017` scrolls with a p95 under 25 ms again (17.7–22.2 ms at 8069cf4), and the conformance P10.30 gained stays.
- cause: Q0.4 bisected the regression to 922271a (P10.36b with P4.74 or P10.26) on one run per step. With `DWELLER_TIMING`, `ui_relayout` p95 goes from 6.2 ms (28df6c8) to 31.8 ms (1021c3f) and 48.5 ms (main), and on main `paint_build` is 47 ms of each scroll-frame relayout. P10.30's `decorateFrom` walks from each text fragment's parent up to the root, twice per fragment, and for every ancestor scans the line's fragments for its baseline (`decoratingBaseline`), measures its font (`textMetrics`) and reads its decoration values before `decorationLines` finds that the box has no line to paint.
- design: `decorateFrom` returns after the walk for a box whose `text-decoration-line` is `none`, before the baseline and the metrics. `decorationLines` paints nothing for such a box, so the display list is the same. Blink computes the applied decorations in the style instead (`core/style/applied_text_decoration.h`); that is a larger change and not needed here.
