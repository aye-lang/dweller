# Q5.14c: a service worker's `fetch` event for an audio or video request

- goal: a controlled page's `<audio>` and `<video>` requests reach its service worker's `fetch` event with `request.destination` `audio` and `video`, as its other requests do (Q5.14a), instead of a panic.
- found: on youtube-search while re-recording sites, the safe build panicked in `callFetchHandler` (index out of bounds).

## Cause

`callFetchHandler` (`browser/engine/call-fetch-handler.aye`) took the destination from a table of seven strings, indexed by the IPC code of the request's kind (`net.requestCode(req)[0]`). Q3.15c (slice 1, 3b9d673c: scripted media elements load) added `Kind.Audio` (7) and `Kind.Video` (8) to `requestCode`, and the table stayed at seven: an audio or video request of a controlled page read past its end.

## Fix

- `requestDestination(kind)` (`browser/engine/request-destination.aye`): an exhaustive `match` on `net.Kind` to the Fetch standard's `Request.destination` (`document`, `style`, `image`, `script`, the empty string for a script's `fetch()`, `font`, `worker`, `audio`, `video`). A new kind is now a compile error there, not a read past a table. The table is gone.
- the other uses of `requestCode`: no other table is indexed by its kind code. `net.codedRequest` maps the code back with a table of nine kinds behind a bounds check (`kind > 8` is `null`), and `ui/hold-fetch.aye` and `ui/finish-held.aye` compare the code with 0 and 4; none reads past an end.

## Test

`serviceworker::serviceworker_destination` (`browser/tests/serviceworker/destination.html`; `worker.js` answers a `?dest` request by posting `<file> <request.destination>` to its clients): a controlled page adds a `<script>` and sets `src` on an `<audio>` and a `<video>`; the page must show `destinations a.js script, a.mkv video, a.wav audio`, in the window with `DWELLER_PROCESS=single` and with `site` (the default).

Before the fix (`call-fetch-handler.aye` of `main` d6b12edd, this test): fails in `single` with `browser/engine/call-fetch-handler.aye:30:46: panic: index out of bounds: index 7, len 7`.
