## Design (step 1, arrays)

- an element with attributes other than writable, enumerable and configurable data lives in the array's `props` under its index key; its slot in `elems` is a hole and `Obj.elems_in_props` is set. A read of a hole already falls through to `props` (`getFrom`).
- `Obj.length_read_only`: `length` is not writable.
- `defineOwnProperty` (`builtins.aye`) on an array: `length` goes to `arraySetLength`; an index goes to `arrayDefineIndex`, which writes `elems` when the result stays default data and else moves the element into `props` (`elemToProp`) so the ordinary algorithm validates it; the final write is `defineElemProp` (extends the length). `arrayLengthTo` shrinks the length and stops above the highest non-configurable element.
