## Design (step 1, arrays)

- an element with attributes other than writable, enumerable and configurable data lives in the array's `props` under its index key; its slot in `elems` is a hole and `Obj.elems_in_props` is set. A read of a hole already falls through to `props` (`getFrom`).
- `Obj.length_read_only`: `length` is not writable.
- `defineOwnProperty` (`builtins.aye`) on an array: `length` goes to `arraySetLength`; an index goes to `arrayDefineIndex`, which writes `elems` when the result stays default data and else moves the element into `props` (`elemToProp`) so the ordinary algorithm validates it; the final write is `defineElemProp` (extends the length). `arrayLengthTo` shrinks the length and stops above the highest non-configurable element.
- `slowArray`: an array with elements in `props`, a read-only `length` or not extensible (frozen included). Only such an array leaves the fast paths:
  - a write (`setOn`, `setIndex`) goes to `setArrayElem` (an element's setter or read-only flag; a new element of a non-extensible array or past a read-only `length` fails, a TypeError in strict code); `arr.length = n` goes to `setArrayLength` (`arrayLengthOf`, `arrayLengthTo`; a read-only `length` fails before the value is converted, as OrdinarySet does).
  - `hasOwn`, `deleteProp` look in `props` for a hole; `ownKeys` sorts the index keys of `props` in with the elements; `JSON.stringify`, `pushArrayLike` (`apply`) and `iterToArray` (spread, for-of: the array iterator) read such an array with `Get`.
  - the VM's keyed store (`vmKeyedDenseElem`) takes the slow path when the array is not extensible or has elements in `props` (the check was `frozen`; `!extensible` covers it, so a store tests one flag more).
  - `Array.prototype`: the methods of `array-generic.js` (forEach, map, filter, reduce, indexOf, find, ...) take the spec's generic path for an array with elements in `props` (`__denseArray`, read once by the script); the other natives read a copy made with `Get` (`thisArray` -> `slowArrayCopy`); the mutators (pop, shift, unshift, splice, reverse, sort, fill) of a slow array run on that copy and write back only what changed, with `setArrayElem` / `deleteProp` / `setArrayLength` throwing as Set and DeletePropertyOrThrow do (`onSlowArray`); push writes its elements and `length` with no read (`slowArrayPush`); `with` does not read the replaced index (`slowArrayWith`).
