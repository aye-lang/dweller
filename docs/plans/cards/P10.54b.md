# P10.54b: responsive images (srcset/sizes), a crash

- goal: the `left` list of P10.54 for real-site image feel: the `corner-shape-zoom-overlap-extreme-values-crash` crash, `sizes` parsing and srcset selection (`parse-a-sizes-attribute-*`, `sizes-auto*`, `viewport-change`), `loading=lazy`, `decode()`, `width`/`height` attributes, `object-*`/`image-*` properties.
- before: `images` 3123/5146 (60.7%) on this build's base.
- cause groups (failing subtests before):
  - crash (1 file, also in `css/backgrounds-borders`): `bottom: -1e100px` reached `roundPx` (paint/glyphs.aye), whose float-to-int cast panics out of range.
  - the WPT checkout had no `/images/` (the shared support images): every `<img>` test loading `/images/*.png` saw a broken image (about 200 subtests were not even counted).
  - `sizes` in an iframe (716 + `sizes-auto` 74): the parent's script read `currentSrc` of images in a scriptless frame document; the request was made lazily in a microtask, so it was `''` and `complete` false; its media was the window's, not the frame's viewport.
  - `sizes` parsing (about 25 per file): a hand split on commas and spaces; no comments, escapes, `ex`/`ch`/`vmin`/`vmax`/absolute units, math functions, `auto`, and `all 1px` / `not print 1px` were taken as media queries.
  - srcdoc frames resolved image URLs against `about:srcdoc`.
- design: `css.sizesWidth` runs the HTML "parse a sizes attribute" over CSS tokens: entries split at top-level commas (`skipComponent` keeps blocks and unclosed functions whole); `sourceSize` takes the last component value as the size (`sourceSizeValue`: a non-negative length in any unit `unitPx` knows, unitless 0, a math function clamped at 0, or `auto` as -1), and the rest must be empty or a `<media-condition>` that matches (`mediaConditionMatches`: the existing `Condition`, requiring it to consume every token, so a media type or a bare `not print` fails). `autoSizesWidth` (engine) gives `auto` the `width` attribute when the image is lazy and `sizes` starts with `auto`, else 300px; no auto entry or no match: 100vw. `imageState` makes the request synchronously for an `<img>` of another document (a frame read by its parent), and `akImageLoad` uses the frame page's own `media`. `updateImages` resolves an `about:` page's images against its inherited base. `roundPx` clamps to ±1e9 device px before the cast (Blink saturates `LayoutUnit` the same way). `wpt.py fetch` adds `images/`.
- files: `browser/css/` (new: `sizes-width`, `source-size`, `source-size-value`, `media-condition-matches`), `browser/engine/` (new: `auto-sizes-width`; wiring in `sources.aye` (the old `slotWidth`/`lengthPx` removed), `image_api.aye`, `images.aye`, `prelude.aye`), `browser/paint/glyphs.aye`, `browser/tools/wpt.py`, fixture `browser/tests/paint/extreme_offset.{html,png}`.
