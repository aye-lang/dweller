# Q6.13g: parser early errors, private names as their own keys

Covers the rows g, i and h of the Q6.13 table and the `delete` and field-initializer halves of k: they are one walk through the parser's early errors, measured together.

- goal: `test262/language` over 80. After Q6.13c 2484 of its failing tests were "expected SyntaxError, the script ran", and about 420 saw private members as string properties.
- cause and design, by rule:
  - a rest element must be last: `[...a, b]`, `{...a, b}` as bindings (`bindingTarget`), as assignment and arrow-parameter patterns (`toPattern`), and `function f(...a, b)` (`params`). 276 + 32 tests.
  - `await` as an identifier, binding or label in an async function or a module, `yield` in a generator or strict code, and the strict-mode reserved words (`let`, `static`, `implements`, `interface`, `package`, `private`, `protected`, `public`): `parse-check-name.aye`, called where a binding name, an identifier reference and a label are read (the escaped spellings too: the cooked text is checked). About 250 tests.
  - `delete` of a private member (also parenthesized) and, in strict code, of a plain identifier: `parse-check-delete.aye`. About 190 tests.
  - `"use strict"` in the body of a function whose parameters are not simple: `functionBody`. About 100 tests.
  - `arguments` and `super()` in a class field initializer (arrow functions inside it included, plain functions not): `Parser.in_field`. 116 tests.
  - private names: the lexer cooks `#x` as U+0001 `#x` (`PRIVATE_NAME_MARK`, the way a symbol's key is U+0001 `@n`), so a private member's key is an atom no string spells. `ownKeys` leaves it out (`is-private-atom.aye`): `Object.getOwnPropertyNames`, `Reflect.ownKeys`, `hasOwnProperty('#x')`, `o['#x']` no longer see private members, and `o['#x'] = 1` no longer overwrites `#x`. A private method's `name` is still `#m` (`parse-member-name.aye`).
- references: ECMA-262 "Identifiers: Static Semantics: Early Errors", "Destructuring Binding Patterns", "The delete Operator: Static Semantics: Early Errors", "Function Definitions: Static Semantics: Early Errors" (the non-simple parameter rule), "Class Definitions: Static Semantics: Early Errors" (ContainsArguments, SuperCall in a field), "Private Names". V8 does the same in `src/parsing/parser-base.h` (`ParseAndClassifyIdentifier`, `ParseRestParameter`, `ParseMemberInitializer`).
- files: `browser/js/parser.aye`, `lex-word.aye`, `interp.aye`; new `parse-check-name.aye`, `parse-strict-reserved.aye`, `parse-check-delete.aye`, `parse-member-name.aye`, `is-private-atom.aye`; `browser/tests/js/289_parser_early_errors.js` and `.out` (Node 22's output).
- verify (on the tree merged with the wave branch):
  - `test262.py run test/annexB test/language test/built-ins -j 4`: language 18112 -> 19624/23210 (84.5%); built-ins 14429/18373 (78.5%), annexB 856/1044 (82.0%). That run lost 36 tests (class fields with a symbol key were made non-enumerable: the private-name test matched symbol atoms); fixed in `interp.aye` (`fieldFlags` uses `isPrivateAtom`), and the rerun of all 8443 class tests against the baseline is 1912 gained, 0 lost, so language is 19660 (84.7%).
  - `env -u HTTPS_PROXY -u https_proxy -u CURL_CA_BUNDLE -u SSL_CERT_FILE cargo test --release --test browser`: 271 passed, 0 failed (after the fix).
  - `jsbench.py` with `BENCH_BASELINE` the binary of `2662662`: geometric mean 0.991 (the same binary against itself reads 0.96 to 0.97 on this machine).
  - `check_taste.py` 0, `check_layers.py` 0, `gen_property_ids.py --check` 0, `aye check browser` 0.
