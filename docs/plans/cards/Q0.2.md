# Q0.2: W7, W8 and jsbench with a fast and a safe build

- goal: today's numbers for interactivity (W7) and first paint (W8), and the JS benchmarks, with a fast and a safe build, so Q1.1 can decide whether the shipped build becomes `--mode safe` (yes when the cost is 5% or less).
- cause: the last W7/W8 table in `browser/engine/PERF.md` is from 2026-10-17 and has only the fast build; the cost of safe mode was not measured.
- design:
  - main 7de2c08, `AYE_REV` 0953905 (the local aye checkout at ec20998, which differs only in docs). `browser/build.sh target/dweller-fast --mode fast` and `browser/build.sh target/dweller-safe --mode safe`.
  - W7: `window_perf.py report --replay` for each binary (`--allow-debug` for safe, which has no `.fast` marker), over `target/sites` (a symlink to the main checkout's archives).
  - W8: `window_perf.py report --live --chrome` for the fast binary.
  - jsbench: `browser/tests/jsbench/run.sh` with `BENCH_BIN=target/dweller-safe BENCH_BASELINE=target/dweller-fast BENCH_REF=none` (interleaved, median of 3).
  - cost of safe mode = the median over sites of the safe/fast ratio of the longest loop and of the scroll p95, and the jsbench geometric mean.
  - every build and run through `scripts/capped.sh`, one after the other.
- files: `browser/engine/PERF.md` (section "Q0.2: fast and safe builds (2026-11-04)"), `docs/plans/cards/Q0.2.md` (new)
- verify: `window_perf.py report --replay` ran for both builds and the table is committed; `python3 browser/tools/check_taste.py` passes.

## Status: done, 2026-11-04

- cost of safe mode: longest loop +9.5%, scroll p95 +1.9%, jsbench +17.6% (geometric mean speedup 0.850). The jsbench cost is over the 5% of Q1.1.
- W7: fast 9 of 20 pass, safe 8 of 20 (mdn 101 ms). Against 2026-10-17, 7 sites changed: mdn now passes; go-docs now fails (loop, scroll); wikipedia-en, wikipedia (ja) and react now fail the scroll p95 too; github no longer fails idle; bbc now fails idle.
- W8: 19 of 20 pass; zol's first paint is 30079 ms (3013 ms on 2026-10-17).
- not profiled: the new scroll p95 failures, go-docs, bbc idle, zol's live first paint.
