# Q2.2a: a renderer process per tab, lifecycle and framing only

- goal: behind `DWELLER_PROCESS=tab` each tab has a renderer process, `dweller --renderer FD`, that speaks the binary IPC of `docs/process-model.md` §2. The lifecycle messages work end to end: `hello`, a stand-in `navigate` → `loaded` (the tab strip shows the renderer's title), `shutdown`. A renderer that dies is noted for its tab; one that sends a malformed or unexpected message is killed. Pixels, input and network stay in the window process (Q2.2b moves the pixels). Without the flag nothing changes.
- cause: Q2.2 needs a renderer process before frames can move; this step proves spawn, framing, checks and crash handling on their own.
- design:
  - `browser/ipc/` (both sides, no syscalls): `Message` (enum, its `kind()` is the type-code table), `encode` (16-byte header: payload length u32, type u16, flags u16 = 0, frame u32, request u32 = 0, then the fields little-endian, bytes as u32 length + data), `nextMessage` (one framed message from a byte buffer: null when incomplete; `DecodeError` `TooLong` over 1 MiB, `UnknownType`, `PastTheEnd`, `LeftOver`), `Reader` (bounds-checked reads), `fromRenderer` (the kinds R→B may send), `consume` (drops the bytes taken).
  - `browser/renderer/` (`serve`, `serveOn`, `answerAll`, `load`, `send`): sends `hello{VERSION, getpid()}`, then reads the socket with blocking `std.fs.File` reads. `navigate{url}` → `engine.load` (no scripts) → `loaded{title, url}` on the tab's frame id; `shutdown`, end of file or anything else → exit. Test hook `DWELLER_TEST_EVIL=malformed`: after `loaded` it sends a 16-byte header of type 0.
  - window side in `ui/` (as Spaces are), reusing `spaces.aye`'s `spawnProgram` (posix_spawnp), `socketpair`, `number`, `waitpid`/`kill`, and `socket.aye`'s `cloexec`, `noSigpipe`, `readSome`, `sendSome`, `closeFd`: `TabProcess` (pid, fd, in/out buffers, hello, loading, url sent, title, `gone`). `pollTabProcesses` (each loop iteration, after `pollAgents`) starts one per tab and services it: `queueNavigate` when the tab's URL differs from the one sent, non-blocking send and read, `takeMessages`. `rendererSent` applies §4's "every message" rule for this group: a known R→B kind; `hello` first, once, frame 0, our version and the spawned pid; `loaded` only while a `navigate` is open, on the tab's frame id (= `TabSlot.id`). A failure logs `bad message: REASON PID` and kills; end of file or a failed send is `gone crashed`. `freeSlot` ends the process (`shutdown`, SIGKILL after `END_MS`). `tabProcessTimeout` caps the loop wait at `POLL_MS` while a renderer has not answered.
  - test hooks: `--events` words `renderer:loaded`, `renderer:gone` (wait), `renderer:kill` (SIGKILL the shown tab's renderer); `--state` line `renderer PID title TITLE` or `renderer PID gone WHY`.
  - written back into the note: the command line `dweller --renderer FD`, the type codes, flags/request id 0, and the stand-in `navigate`/`loaded` pair.
  - not in this step: `DWELLER_IPC_LOG`, the IO thread and SDL wake event (the loop polls), `init`, sad-tab UI (Q2.5), a respawn after a crash.
- files: `browser/ipc/*.aye` (new), `browser/renderer/*.aye` (new), `browser/ui/{tab-process,start-tab-process,poll-tab-processes,service-tab-process,queue-navigate,read-tab-process,take-messages,renderer-sent,drop-tab-process,end-tab-process,tab-process-timeout,renderer-waits,write-tab-process}.aye` (new), `browser/ui/window.aye`, `tabs.aye`, `script.aye`, `browser/main.aye`, `tests/browser.rs` (`window_renderer_lifecycle`), `docs/process-model.md`, `docs/plans/cards/Q2.2a.md` (new)
- verify: `aye test browser --module ipc` (every message round-trips through the framing; the four bad cases; `fromRenderer`) and `aye check browser`; `cargo test --release --test browser -- window_renderer_lifecycle` (title "Form" from a renderer whose pid is not the window's; `renderer:kill` → `gone crashed`; `malformed` → `gone UnknownType` and the `bad message` line; no renderer without the flag); `cargo test --release --test browser -- window_` exits 0; `python3 browser/tools/check_taste.py` exits 0.
