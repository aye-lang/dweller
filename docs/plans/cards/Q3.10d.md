# Q3.10d: link events without polling; one fetch per sheet URL; a failing `@import` is an `error`

- goal: the `<link>` task of Q3.10c polled at 50 ms twice and `link_events_in_renderer` waited a fixed 150 frames. A sheet is now fetched once per document and request mode however many links name it, and a sheet whose `@import` fails fires `error` on its link.
- source: Q3.10c's Left.
- design:
  - No polling. The link task (`linkUpdate` in the prelude) asks `ak.linkLoad` for the style pass's result; when none is known it runs the pass at once (`getComputedStyle(document.documentElement)`, which fetches and notes the result) and asks again with `last` set, which fetches itself only for a link no pass reads (media that does not match, a disabled sheet). The `setTimer` retries are gone.
  - Per-URL results. `dom.FetchedSheets` (`Document.fetched`, `dom/fetched-sheets.aye`) keeps the response of each sheet fetch for the life of the document, keyed by URL without the fragment and request mode (0 no-cors, 1 `crossorigin` anonymous, 2 `use-credentials`; `engine/sheet-mode.aye`). `sheetFetch` (`engine/sheet-fetch.aye`) serves `linkedSheet` from it, so two links to one sheet, an `@import` of it, and a later style pass share one fetch; a non-cacheable (`no-store`) sheet is fetched once per document, as Chromium's `ResourceFetcher` reuses a resource within a document. A network error is not kept (the next pass tries again); a non-2xx answer is. `sheetHrefs` leaves memoised sheets out of the prefetch batch, so `stylingWithoutFetch` no longer waits for them.
  - `@import` failure. `noteFailedSheet` counts failed sheet fetches; `linkedSheet` notes `LINK_FAILED` for the importing sheet when the count moved while its rules were parsed (nested imports too), so the link fires `error` and `link.sheet` is null. The rules that did load stay applied.
  - Test timing. `net/link-events.html` sets `document.title = 'link events done'` after its last line; `link_events_in_renderer` waits for `renderer:title:done` in the tab process (`renderer:loaded renderer:title:done`) and for nothing in the in-process window, which ends when the page is idle. No frame count.
