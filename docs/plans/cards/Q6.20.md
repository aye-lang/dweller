# Q6.20: the UA sheet raises `<sup>` and lowers `<sub>`

- goal: W3 (P1.S9, 2026-11-25) found reference marks such as [1] on both Wikipedias drawn on the baseline; Chrome raises them.
- cause: `browser/css/ua.aye` had only `sub, sup { font-size: smaller }`. Layout already shifts `vertical-align: super` and `sub` (`browser/layout/align-shift.aye`, Blink's `inline_box_state.cc`), but the UA sheet never set them.
- change: `sub { vertical-align: sub; font-size: smaller }` and `sup { vertical-align: super; font-size: smaller }`, as Chromium's `html.css`.
- goldens: `browser/tests/style/ua_defaults.style` (`<sub>` gets `vertical-align: sub`) and `browser/tests/layout/headings.layout` (the `<sub>` moves 4.2 px down, 16 / 5 + 1; its line grows 24 → 26.29 px, as in Chrome, where a shifted inline box can grow the line). No other style, layout or paint golden changed.
- check: `page_load.py check --screens --site wikipedia-en`: the marks [6], [7][8], [9] are raised (Wikipedia's own `sup { line-height: 1 }` keeps the lines even). The reference-mark defect is removed from both Wikipedias' `visual` in `browser/tools/sites.json`; their other defects remain.
