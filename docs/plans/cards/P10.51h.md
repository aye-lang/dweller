# P10.51h: transition texts stay bounded; form states and iframe hover measured

- goal: (1) `Transitions.kept` stops growing (the reference sweep P10.51e describes); (2) hover in iframes restyles locally in the frame; (3) `:checked`, `:disabled`/`:enabled`, `:placeholder-shown`, `:valid`/`:invalid`, `:target` go through the per-key state invalidation (P10.51g); (4) sibling invalidation sets. P10.51g's "left" list.
- design:
  - `keptValue`: a transition's from/to/reversing-start text and a transform snapshot reuse an equal text already in `kept` instead of copying it again.
  - `sweepKept` (after `startTransition` appends, when `kept` holds more than 16): frees the kept texts no running transition, `before` snapshot or `shown` values array points at (`keptInUse`, by pointer). The shown arrays are the ones `Styles` holds for the transitioned elements, so the boxes a local restyle keeps still point at live texts.
  - `noteKept`: a `transitions_kept` timing record (`kept frames`) after each `showTransitions` with a running transition.
- files: `browser/animation/` (`kept-value.aye`, `sweep-kept.aye`, `kept-in-use.aye`, `values-use.aye`, `uses-text.aye`; wiring in `start-transition.aye`, `snapshot-value.aye`); `browser/engine/note-kept.aye` (wiring in `show-transitions.aye`). Tests: `tests/browser.rs` `window_transition_kept`; fixtures `browser/tests/ui/form_states.html` (10 checkboxes, a disabled one, 5 required fields with placeholders, `form:invalid`, `:target`), `hover_frame_local.html` (an `srcdoc` iframe with `a:hover`, `.card:hover .t`).
- reference: blink `core/animation/css/css_animations.cc` (transition cleanup); algorithm only. https://drafts.csswg.org/css-transitions-1/#starting
- verify: fast build; `DWELLER_TIMING=1 [DWELLER_LAYOUT_CHECK=1] target/dweller browser/tests/ui/hover_transition.html --font fixed --width 400 --height 300 --frames 1100 --events "painted (move:120,160 frame move:300,250 frame)×250"`; P10.51f/g's focus_local/hover_local commands; form_states (800×700, 120 frames, 10 checkbox clicks at x=5, a click in a field, `text:ab`, two backspaces); hover_frame_local (800×600, 60 frames, 10 moves at x=20); `cargo test --release --test browser -- window_ screenshot_ paint scroll style_fixtures layout_fixtures jsdom_fixtures`; `check_taste.py`, `check_layers.py`.
- status: partial 2026-10-18 (goal 1 done; 2–4 left).
  - 500 hover moves over the transitioned box: `kept` 2005 at the end before, at most 16 after (fast build); the debug build in `window_transition_kept` stays ≤ 32 (it reached 32 after 100 frames with dedupe alone, before the sweep).
  - Unchanged by this card (same numbers before and after, `DWELLER_LAYOUT_CHECK=1` clean on all, 0 CHECK lines): hover_local `style_full` 1, `layout_full` 1 (the load), restyled 4–8 per move; focus_local 6–7 per move; hover_frame_local `style_full` 2, `layout_full` 2, restyled 4–8 per move; form_states `style_full` 10, `layout_full` 10: each checkbox click is a full restyle and layout (the baseline for goal 3).
  - tests: 69/69 with `window_transition_kept`; `window_css_animation` failed once in the full run under load and passed 2/2 alone (as in P10.51f). No golden changed. `check_taste.py`, `check_layers.py` pass. `conformance.py` not run (no selector or form code changed).
- left:
  - `Transitions.frames` (interpolated transform texts) still grows while transitions keep running (998 after the 500 moves); it is dropped only when nothing runs or shows. The same sweep could cover it once `Styles.shared` arrays that no element holds are not read (`hashValues`/`sameBits` read their keyword texts).
  - Form states (goal 3): a checkbox toggle changes `controlInputs` (the `checked` bits), which unshares the layout. Plan: a `FORM_STATE_CHANGED` key (`simpleKeys` for `:checked`/`:indeterminate`/`:disabled`/`:enabled`/`:placeholder-shown`/`:valid`/`:invalid`), `setChecked` notes each changed radio/checkbox (and the form/fieldset owners for `:valid`/`:invalid`), `isPointerState` accepts it, and `controlInputs` subtracts the contribution of noted controls so an un-noted change still falls back to a full restyle. `:target` the same at navigation.
  - Iframe hover (goal 2) and sibling invalidation sets (goal 4): not started.
