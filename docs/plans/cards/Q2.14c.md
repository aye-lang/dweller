# Q2.14c: the in-process arm of a two-arm test says that it is in process

- goal: Q2.14a's proposed readiness row 2 (cause rows 4, 7 and 8, 21 tests): the arm of a tab-versus-window test that means the window's own process keeps that meaning when the run has `DWELLER_PROCESS=site`, and after Q2.14 makes `site` the default.
- source: `docs/plans/cards/Q2.14a.md`, "Proposed readiness rows" 2. The branch `q2-14c-explicit-arms` (commit aa967b4) had no card; this one is written at its merge (wave 2026-11-16).
- design: the browser reads every `DWELLER_PROCESS` value but `tab` and `site` as the window's own process, so the arm sets `DWELLER_PROCESS=single` (`IN_PROCESS` in `tests/browser.rs`) and no product code changes. `in_renderer(envs)` is true for an arm that names `tab` or `site`; `login_window_with` adds its `renderer:` waits only then. `docs/process-model.md` §3 "Modes" lists `single`.
- files: `tests/browser.rs` (`IN_PROCESS`, `in_renderer`), `tests/browser/{link_events,window_login,window_renderer,window_renderer_edit,window_renderer_oopif,window_spaces}.rs`, `docs/process-model.md`.
- verify (2026-11-16, Linux x86_64, 4 cores, the whole suite with `DWELLER_PROCESS=site`, run 1 of this wave after the merge of Q2.14b, c and d: 180 / 249):
  - of the 21 tests of rows 4, 7 and 8, 18 pass: `window_login`, `window_login_basic`, `window_login_forms`, `window_login_storage`, `window_login_cookies`, `window_renderer_input`, `window_renderer_focus`, `window_renderer_arrow_keys`, `window_renderer_clipboard`, `window_renderer_find`, `window_renderer_frame_click`, `window_renderer_oopif_pixels`, `window_renderer_lifecycle`, `window_renderer_samesite`, `link_events_in_renderer`, `window_renderer_targets`, `window_spaces_chips`, `window_spaces_chips_in_renderer`.
  - 3 still fail, for a cause that is not the arm: `window_login_basic_cancel`, `window_login_basic_prompt`, `window_login_popup` (their messages are in Q2.14h).
  - the default mode: unchanged (`single` is the default until Q2.14); the suite in the default mode is 249 / 249 on the wave branch.
