# V6: an abstract node tree

The card is in `docs/plans/vision.md`.

## Status: not started, 2026-11-16: deferred by this lane, with the audit below

Decision (lane native, wave 2026-11-16): V6 is not done in this wave.
The reasons, by the plan's own rules:

1. It has no user yet. `docs/vision.md` says the abstract tree "comes
   when the TUI needs a second implementation (V6), not before". After
   V3, a component builds a `dom.Document` through the shell's DOM
   functions on every target, so the TUI backend (V7) lays out the same
   `dom.Document` with a cell measurer and needs no second tree. V7's
   "depends on V6" no longer holds; V7 was done without it.
2. It is the opposite of this wave's rule for a worker ("new code goes in
   new files, another lane's files are changed by the smallest seam").
   The change is signatures and call sites in files that the css-layout,
   css-values, css-writing and proc lanes are changing now:
   `css/cascade.aye` and `css/values.aye` were changed five times each on
   the wave branch in two days.
3. "No slowdown" rules out a `dyn` interface on the cascade's hot path
   (`doc.node(h)` is a field read today), so the tree would be a type
   parameter of `computeStyles`, `layoutDocumentWith` and what they call.
