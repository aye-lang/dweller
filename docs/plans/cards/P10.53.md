# P10.53: css/inline-text toward its threshold

- goal: WPT area `css/inline-text` (`css/css-inline`, `css/css-text`, `css/CSS2/linebox`) from 34.9% toward its 60% threshold; writing-mode is left to its own card.
- before: on `train-2` (`conformance.py run css/inline-text`) 2817/8083 (34.9%). The 2251/8075 row in `history.csv` was measured on an older checkout.
- cause groups (failing subtests before, 5266):
  - `i18n` line breaking by class, CJ and PO/PR rules for `line-break: loose|normal|strict` (1080, not started).
  - interpolation and composition (967 in `css-text/animations`, 156 in `css-inline/animation`): missing longhands (`tab-size`, `hyphens`, `hyphenate-character`, `hyphenate-limit-*`, `line-break`, `text-align-last`, `text-justify`, `dominant-baseline`, `alignment-baseline`, `baseline-source`), and CSS Transitions never started for any longhand after `transition-property` in `PROPERTIES` (`letter-spacing`, `word-spacing`, every newer one).
  - `white-space` reftests (512) and `white-space` as a shorthand of `white-space-collapse` and `text-wrap-mode` (`white-space-shorthand` 40, not started).
  - parsing (583 in `css-text/parsing` and `css-inline/parsing`): missing longhands, and `e.style[p] = v` stored invalid values (every `*-invalid.html`).
  - `text-box-trim`/`text-box-edge` (318 with parsing), `text-transform` reftests (261), `text-justify` (234), `baseline-source` layout (207), `initial-letter` (91), `word-break`/`line-breaking`/`hyphens`/`overflow-wrap` reftests (~300): not started.
- design: 14 longhands are table lines in `PROPERTIES` (`word-break`, `overflow-wrap`, `line-break`, `hyphens`, `white-space-collapse`, `text-align-last`, `text-justify`, `dominant-baseline`, `alignment-baseline`, `baseline-source`, `text-group-align`, `tab-size`, `hyphenate-limit-lines`, `hyphenate-character`); layout does not read them yet. `text-align` accepts `match-parent` (computes to the parent's value, `start`/`end` resolved to `left`/`right` by the parent's direction; `start` on the root) and `justify-all`. Setting a longhand through `element.style` checks the value with the stylesheet parser (`parsesAs`) for keyword, length, number, integer and line-height longhands and ignores an invalid one (CSSOM `setProperty`); `vertical-align`, `text-indent` and `text-transform` keep their old behavior, as the parser does not take all their valid forms yet. Transitions run on every longhand (the transition and animation longhands are keyword lists, which do not interpolate).
- files: `browser/css/css.aye`, `property-ids.aye` (generated), `specified-value.aye`, `cascade.aye` (wiring); new `browser/css/parses-as.aye`, `checks-value.aye`, `fix-match-parent.aye`; `browser/animation/change-style.aye`.
