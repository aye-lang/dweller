# Q3.1c: every request names its initiator (fail-closed)

- goal: a `net.Request` that does not say who asked does not compile. Before, `initiator: []u8 = ""` defaulted to "the browser asked", which may load `file:`: every site that forgot the field was silently treated as the browser (fail-open).
- design:
  - `net/initiator.aye` (new): `enum Initiator { Browser, Page { url: []u8 } }`. `Page.url` is the asking page's URL (`initiatorOf`: the origin page's URL, so `about:blank` and `srcdoc` frames ask as their creator).
  - `Request.initiator: Initiator`, no default. `initiatorMayLoad(Initiator, *Url)`: a non-`file:` target always; `file:` for `Browser`, or a `Page` whose URL is `file:`.
  - the chain that carried `initiator: []u8` (with `""` for the browser) carries `net.Initiator`: `fetchLocal`, `loadWith`, `loadParsed`, `fetchPage`, `navigateFrame`, `navigateTo`, `Tab.navigate`, `Tab.navigateEarly`, `ui go`, agent `goTo` and `loadInFrame`. `initiatorOf(p)` returns `Initiator.Page`.
  - `ContextRequest` (window.open, named targets) keeps the asking page's URL as owned bytes, as before; `loadInTab` makes it `Initiator.Page`. Its only producers are page scripts.
  - a redirect keeps the original initiator: `http.aye` reuses the same `Request` for each hop, and the loader never follows a redirect off `http(s):`.
- sites (choice):
  - `net/net.aye` `fetch`: Browser (the command line URL, `main.aye`, unit tests).
  - `net/net.aye` `fetchWith`: Browser (same contract as `fetch`; no callers today).
  - `net/archive.aye:98` `fallback` GET key: the asking request's own initiator (only a hash key).
  - `net/loader.aye` `startLoad` (:144): Page, the load's referrer (a page's image or script).
  - `net/loader.aye` `startHop` (:375): Page, the load's referrer (a script's fetch/XHR, a frame's background load).
  - `net/loader.aye` `endRequest` (:410): Page, the load's referrer (the archive record of the same request).
  - `net/loader.aye` `finishLoad` redirect (:668): Page, the load's referrer (the redirect keeps the page as initiator).
  - `engine/frames.aye` `startFrameLoads` (:243): Page, `initiatorOf(p)` (the parent page's iframes).
  - `engine/frames.aye` frame history entry (:534): Browser (history traversal).
  - `engine/engine.aye` `load`: Browser (command line, `shot`, unit tests).
  - `engine/engine.aye` `loadState`: Browser (history traversal).
  - `engine/traverse-early.aye`: Browser (history traversal in the window).
  - `ui/window.aye` `start` first page and `submitAddress`: Browser (command line, address bar).
  - `agent/actions.aye` `navigate`: Browser (the agent typed it).
  - `engine/contexts.aye` `loadInTab`: Page, the opener's URL (window.open, `target=`).
  - `engine/fonts.aye`, `images.aye`, `sheets.aye`, `js/module-response.aye`: Page, the referrer (the page's own subresources).
  - `engine/workers/load-bytes.aye`, `worker-module-response.aye`: Page, the worker's scope URL.
  - `engine/inserted.aye`, `script.aye`, `wk-fetch.aye`, `window_api.aye` fetch, links, forms, frames, `scripts.aye`: Page, `initiatorOf` (unchanged choice from Q3.1, now typed).
  - `net/cookies.aye` test requests: Page with the test referrer where there is one, else Browser.
- holes: `frames.aye:243` and the four loader sites were page loads that defaulted to Browser. Not reachable for `file:` today (the loader takes only `http(s):` and drops redirects off it), but they would have been the first time someone routed a `file:` load through them.
