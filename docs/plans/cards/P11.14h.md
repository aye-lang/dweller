# P11.14h: OffscreenCanvas in workers, transferControlToOffscreen, module-import MIME check

- goal: P11.14g's left 1, 2 and 4: (1) `OffscreenCanvas` in the worker scope with a per-Interp bitmap table instead of the page's `ImageCache`, 2D first, then WebGL with a context current on the worker thread; (2) `HTMLCanvasElement.transferControlToOffscreen`, an OffscreenCanvas transferable through `postMessage` (`wire.js` `{t: 'C', id, p, w, h}`), `commit()`/rAF in the worker presenting frames to the placeholder; (3) the module-worker JavaScript MIME check and CORS for module imports. Target: the `offscreencanvas/*-worker` CTS pages.
- design:
  - Worker canvas host: `workers.Link.scope_hook` (a `ScopeHook`, set by `wkStart` to `installWorkerCanvas`) runs after the worker scope is installed. It gives `workers.Scope` a `Bitmaps` table (`WorkerBitmaps`: the worker's `CanvasBitmap`s, keyed by host objects with tag `TAG_WORKER_CANVAS` = 2, no `HOST_NAMED` bit), installs `__canvasHost` with the WebGL natives plus `workerCanvas`/`workerResize`/`workerFrame`, and runs the page's WebGL preludes and `CANVAS_PRELUDE` unchanged inside one function whose parameters shadow `HTMLCanvasElement`, `HTMLImageElement`, `HTMLVideoElement` and `document` with worker stubs (`worker-canvas.js`): `document.createElement('canvas')` makes a worker canvas node, so the page's `OffscreenCanvas` class runs as is and nothing DOM-like leaks into the worker global.
  - `canvasBitmap` and `canvasChanged` take the worker path when the Interp's host is a worker scope (`workerBitmapsOf`); the page path is untouched. `Scope.finalize` drops a collected canvas (its GL context too); the worker frees the table before its Interp.
  - GL on the worker thread: no change to `gpu`. `drawing_buffer.aye`'s `current` caches the last context made current by any thread; each context is used by one thread only, and only that thread stores its EGLContext there, so `current == self.egl` still means self is current on the calling thread (a switch by another thread only costs one extra `eglMakeCurrent`). Aye has no thread-locals; `eglGetCurrentContext` per call would add a call to every main-thread GL entry.
  - `transferToImageBitmap` of a WebGL OffscreenCanvas clears the drawing buffer (`webglDiscard` → `Context.clearBuffer`, now public) instead of re-setting the width, which did not clear it.
  - Placeholders (`canvas-placeholder.js`, page): `transferControlToOffscreen` gives the canvas an id and returns an OffscreenCanvas with `_placeholder`; a second transfer and `getContext` on the placeholder throw InvalidStateError. `wire.js` accepts an OffscreenCanvas only in the transfer list, encodes `{t: 'C', id, p, w, h}`, marks the sender `detached`, and decodes to a new OffscreenCanvas with that placeholder. Main-thread `commit()` draws the offscreen canvas into the placeholder.
  - Worker frames (`worker-commit.js`, `ak-worker-frame.aye`): `commit()` and the worker's `requestAnimationFrame` (16 ms timer, then every placeholder-bound canvas with a context commits) end the WebGL frame (`startFrame`/`takeFrame`: preserveDrawingBuffer clearing as on the page) and post a `FRAME` message (`{id, w, h}` + the RGBA bytes); `worker-page.js` hands it to `__placeholderFrame`, which `putImageData`s it into the placeholder's 2D bitmap (its own internal context), so paint and screenshots show it.
  - Module imports: the page answers a worker fetch with the response's MIME type as the answer's JSON (`answerWorker(l, body, mime)`); `workerModuleResponse` (through the new `askPage`) builds the response with it, so the module loader's existing `isModuleMime` check refuses a `text/plain` import. `blob:` answers carry no type and are taken as JavaScript.
- files: `browser/engine/{worker-bitmaps,worker-bitmap,worker-bitmaps-of,find-worker-bitmap,add-worker-bitmap,resize-worker-bitmap,release-worker-bitmap,drop-worker-bitmap,install-worker-canvas,worker-canvas-preludes,ak-worker-canvas,ak-worker-resize,ak-worker-frame,ak-webgl-discard,canvas-placeholder-prelude}.aye`, `browser/engine/{worker-canvas,worker-commit,canvas-placeholder}.js`, `browser/engine/workers/{bitmaps,scope-hook,ask-page}.aye`; wiring in `canvas_api.aye`, `canvas_prelude.aye`, `webgl_api.aye`, `script.aye`, `wk-start.aye`, `wk-fetch.aye`, `wk-answer.aye`, `answer-worker.aye`, `workers/{scope,link,message,set-up-worker,run-worker,fetch-through-page,worker-module-response,wire.js,worker-page.js}`, `browser/gpu/drawing_buffer.aye` (`clearBuffer` public); test `worker_canvas` (`browser/tests/workers/canvas.{html,png}`, `canvas-worker.js`); `browser/tools/conformance/*` + `docs/conformance.md` (generated).
