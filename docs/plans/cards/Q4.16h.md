# Q4.16h: a delete keeps the object shaped

- goal: Q4.16a's ranked step 7. `removeProp` set `shape = NONE`, so after a `delete` every load on the object (and every load through it as a prototype) left the inline cache. On bbc that was 3.7M slow loads (Q4.16a), about 60 ms by Q4.21 once Q4.23 made prototypes shaped again on load.
- design (V8 `DeleteObjectProperty`: deleting the last added property rolls the map back to its parent):
  - `shapeAfterRemove`: when the deleted property is the last one in the object's layout (its shape's key and slot), the object takes the shape's parent. No new shape is made; the parent's slots are the object's.
  - another delete: the object is made shaped again from its remaining properties (`heapMakeFast`, Q4.23's prototype path: at most 8 times per object, under `MAX_SHAPE_PROPS`). Past that it stays a dictionary as before, so an object used as a hash table with many deletes does not keep making shapes.
  - `heapProtoChanged` still runs first, so a cached prototype chain through the object is checked again.
- files: `browser/js/heap.aye` (`removeProp`), new `browser/js/shape-after-remove.aye`; new test `browser/tests/js/295_delete_shapes.{js,out}` (keys, values and order after deleting the last key and a middle key, twins that share a layout, a polymorphic load site, a prototype method deleted and added again, `delete Function.prototype.x` then `call`, 14 deletes from 40 keys, an accessor kept; `.out` from node 22).
- references: v8 `src/runtime/runtime-object.cc` (`DeleteObjectPropertyFast`), `src/objects/js-objects.cc` (`JSObject::MigrateSlowToFast`).
- verify (2026-11-22, Linux x86_64, 4 cores; proxy variables unset):
  - a micro benchmark (`o.a + o.b`, 3M iterations): an object never deleted from 153 ms; after deleting its last key 437 -> 160 ms; after deleting a middle key 465 -> 152 ms.
  - test262 (d53ebc8b19): `language` 20047/23210, `built-ins` 15820/18373, `annexB` 856/1044, as before; no test that passed fails (the one `built-ins` file below the committed baseline, `Object/defineProperty/coerced-P-shrink.js`, fails with the binary from before too).
  - `cargo test --release --test browser -- js_conformance`: pass (with the new test). jsbench (`BENCH_BASELINE` the build before, median of 3): geometric mean 1.027; `three` 0.92 and `globals` 0.94 are the lowest, `raytrace` 1.26 the highest.
