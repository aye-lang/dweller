# Q6.13d: built-in methods are not constructors

- goal: the `not-a-constructor.js` cluster (384 failing in `test262/built-ins`, 19 in `annexB`).
- cause: every native function could be called with `new`, and `Reflect.construct` accepted any function as target or new target, so `Reflect.construct(function () {}, [], Math.abs)` did not throw.
- design:
  - `is-constructor.aye` (`isConstructor`, ECMA-262 IsConstructor): a closure unless it is an arrow, method, generator or async function; a native when it has an own `prototype` property (every native constructor of the engine and of `browser/engine` has one) or is marked (`NativeEntry.constructs`, set for `Proxy`, which has no `prototype`: `proxy-constructor.aye`); a bound function when its target is one; a callable proxy.
  - `Interp.constructAt` throws "is not a constructor" for a native that is not one; `engineConstruct` (`Reflect.construct`) checks the target and the new target.
  - built-ins written in the prelude as `function` expressions are marked as methods with the new `__engine.method(f)` (`engine-method.aye`, sets `FuncInfo.method`): `escape`, `unescape`, `structuredClone`, `Iterator.from`, the `Date` setters, `Date.prototype[Symbol.toPrimitive]`, the `DataView` accessors, `Number.prototype.toLocaleString`.
- references: ECMA-262 "Built-in Function Objects" ("Built-in function objects that are not identified as constructors do not implement the [[Construct]] internal method"), IsConstructor, `Reflect.construct`. V8: `Builtins::Generate_ConstructFunction` / `non_constructor` builtins.
- files: `browser/js/interp.aye`, `coroutine.aye`, `proxy.aye`, `lib.aye`; new `is-constructor.aye`, `engine-method.aye`, `proxy-constructor.aye`; `browser/tests/js/288_builtin_not_constructor.js` and `.out` (Node 22's output; `structuredClone` is left out of it, Node's is a constructor).
- verify:
  - `test262.py run test/annexB test/language test/built-ins -j 4`: built-ins 14045 -> 14429/18373 (78.5%), annexB 849 -> 856/1044 (82.0%), language 18112/23210 (78.0%); 0 lost against the baseline of the row.
