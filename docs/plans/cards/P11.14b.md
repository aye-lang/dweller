# P11.14b: WebGL 1 context and the largest WebGL conformance failure groups

- goal: from P11.14's data: (1) `WebGLRenderingContext` as a real interface and `getContext('webgl')` / `'experimental-webgl'`; (2) a second `getContext` and WebGL canvases as texture sources; (3) integer formats and the DOM-source format matrix of `texImage*`.
- design:
  - The WebGL 2 context restricted to the WebGL 1 surface, as Blink's `WebGLRenderingContext` shares `WebGLRenderingContextBase`. An ES2-level ANGLE context was rejected: the drawing buffer uses ES3 (`glTexStorage2D`, multisample renderbuffers, blits, PBO readback, fences).
  - `webgl1.js` builds `WebGLRenderingContext` (illegal constructor). Its prototype takes the WebGL 1 IDL methods, the accessors and the private helpers from `WebGL2RenderingContext.prototype`. It takes the WebGL 1 constants: the table up to `INVALID_FRAMEBUFFER_OPERATION`, plus `DEPTH_STENCIL`, `DEPTH_STENCIL_ATTACHMENT` and the five `*_WEBGL`. A WebGL 2 context is not an instance of it.
  - WebGL 1 behaviour: `VERSION` `WebGL 1.0`, `SHADING_LANGUAGE_VERSION` `WebGL GLSL ES 1.0`. `#version 300 es` shaders fail to compile; `getShaderSource` still returns the given source. `texImage2D`/`texSubImage2D` take only `ALPHA RGB RGBA LUMINANCE LUMINANCE_ALPHA` with `UNSIGNED_BYTE` or the packed 16-bit types (else `INVALID_ENUM`). `internalformat` must equal `format` (else `INVALID_OPERATION`). The extensions are the ones WebGL 1 and 2 share; the WebGL 1-only set comes with P11.29.
  - `__webgl.create1` makes a WebGL 2 context and gives it the WebGL 1 prototype. `__webgl.is` tells either kind; `canvas_prelude.aye` uses it for snapshots, `toDataURL` and `drawImage`. `getContext` returns null for the other kind.
