# P11.12: the rest of WebGL 2

- goal: queries (`ANY_SAMPLES_PASSED`, `ANY_SAMPLES_PASSED_CONSERVATIVE`, `TRANSFORM_FEEDBACK_PRIMITIVES_WRITTEN`; results only after control returns to the event loop), `fenceSync` / `clientWaitSync` (timeout clamped to 0) / `waitSync` / `getSyncParameter`, transform feedback, `readPixels` into a `PIXEL_PACK_BUFFER`, `getBufferSubData`, `copyBufferSubData`, `copyTexSubImage2D`/`3D`, `clearBufferfi`, `invalidateFramebuffer`/`invalidateSubFramebuffer`, `getIndexedParameter`, `getInternalformatParameter`, and the P11.8b getters `getBufferParameter`, `getVertexAttrib`, `getVertexAttribOffset`. `blitFramebuffer`, `readBuffer`, `drawBuffers`, instanced and range draws had already landed in P11.8.
- design:
  - The JS lives in `browser/engine/webgl2-rest.js` (embedded by `webgl2-rest-prelude.aye`, run right after `WEBGL_PRELUDE` in `script.aye`). It adds methods to `__webgl.Context.prototype` and wraps four old ones only to add behavior: `readPixels` (a bound pack buffer takes a byte offset; a view is then `INVALID_OPERATION`), `getParameter` (`TRANSFORM_FEEDBACK_BINDING`), `bindBuffer`/`bindBufferRange` (remember GL name → `WebGLBuffer`, so `getIndexedParameter` and `getVertexAttrib(VERTEX_ATTRIB_ARRAY_BUFFER_BINDING)` give the object GL reports).
  - Availability as Blink's `WebGLQuery`/`WebGLSync`: `endQuery` and `fenceSync` reset the cached result and allow one GL poll only after a `setTimeout(0)` task; until then `QUERY_RESULT_AVAILABLE` is false and `SYNC_STATUS` is `UNSIGNALED`. `clientWaitSync` with a timeout > 0 (`MAX_CLIENT_WAIT_TIMEOUT_WEBGL` is 0) is `INVALID_OPERATION` + `WAIT_FAILED`; otherwise `ALREADY_SIGNALED`, `CONDITION_SATISFIED` (this poll) or `TIMEOUT_EXPIRED`, polling GL with `glClientWaitSync(s, 0, 0)`. `waitSync` is a no-op after its argument checks.
  - Blink's checks on top of ANGLE: one active query per target slot, query target fixed at the first `beginQuery`, no parameter of an active or never-begun query; `bindTransformFeedback` while active and unpaused and deleting an active transform feedback are `INVALID_OPERATION`; `getBufferSubData` of the transform feedback buffer while active, offsets/sizes negative, the element-array mix in `copyBufferSubData`; `getInternalformatParameter` only `RENDERBUFFER`/`SAMPLES`, integer formats give an empty `Int32Array`, float formats need `EXT_color_buffer_float` (half float also `EXT_color_buffer_half_float`). On the drawing buffer (a real FBO), `invalidateFramebuffer` maps `COLOR`/`DEPTH`/`STENCIL` to its attachments and rejects `COLOR_ATTACHMENTi` with `INVALID_ENUM`. Everything else is ANGLE's WebGL validation.
  - Natives: `webglRest` (`webgl-rest.aye`, ops 0–25: queries, transform feedback, copies, `clearBufferfi`, pack readback, indexed / buffer / attribute getters, fences; a GLsync crosses to JS as its pointer bits in a number), `webglRestView` (`webgl-rest-view.aye`: `getBufferSubData` by `glMapBufferRange`, invalidate, sample counts, `CURRENT_VERTEX_ATTRIB`, `transformFeedbackVaryings` via `feedback-varyings.aye`), `webglFeedbackVarying` (`webgl-feedback-varying.aye`). 26 `gl.aye` entry points.
- files: `browser/engine/webgl2-rest.js`, `webgl2-rest-prelude.aye`, `webgl-rest.aye`, `webgl-rest-view.aye`, `webgl-feedback-varying.aye`, `feedback-varyings.aye`, wiring in `webgl_api.aye` and `script.aye`, `browser/gpu/gl.aye`, `browser/tests/webgl/webgl2_rest.html` + `.txt`, `tests/browser.rs` (`webgl2_rest`).
- reference: `third_party/blink/renderer/modules/webgl/webgl2_rendering_context_base.cc`, `webgl_query.cc`, `webgl_sync.cc`, `webgl_transform_feedback.cc` (algorithm only).
- verify: `cargo test --release --test browser -- webgl2_rest` → 0; `cargo test --release --test browser -- gpu webgl screenshot_` → 0 (14 passed, no golden changed).
