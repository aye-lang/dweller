# P4.75u: the navier-stokes regression; direct native calls

- goal: (1) no jsbench benchmark slower than base `c996cf8` beyond noise after P4.75s (navier-stokes was 0.89×); (2) a native callee of `CallProperty`/`CallUndefinedReceiver` is called straight from the dispatch loop; (3) the closure call path.
- regression findings (fast build, 4-core Xeon, interleaved runs, medians of 7 to 11): bytecode count is identical base vs P4.75s (508,146,195), so the cost is per opcode. `perf` (timer samples only, no PMU on this VM) puts 94–95% in `vmLoop` in both; the dispatch sequence is the same instruction for instruction. Reverting one P4.75s fast path at a time: without `vmContextCell` 2.46 → 2.40 s; without it and the typed keyed checks no clear change; with all three in-loop fast paths reverted (also `vmGlobalCell`) 2.29 s vs base 2.35–2.42 s, but `globals` drops back from 0.45 to 0.62 s. So the cost is the code generated for `vmLoop` (register allocation/spills around the inlined fast paths), not one opcode; no single change removes it without losing the gains. The run-to-run noise on this box is ±3%.
- design (2): `vmNativeCallee` checks for a `Native` function (not a direct `eval` site); `vmCallNativeAt` builds `Args` over the caller's registers (r+1 `this`, r+2.. the arguments, as V8's `Arguments` points into the interpreter frame) and calls `callNative`: no copy to the stack top, no `vmInlineCallee`, no `vmCallOp`, no `callAt`. `vmCallOp` now finds the Call node (`vmCalleeNode`) only on the not-callable path.
- files: new `browser/js/vm-native-callee.aye`, `vm-call-native-at.aye`, `vm-callee-node.aye`; wiring in `vm.aye` (ops 77, 78, `vmCallOp`).
- reference: v8 `src/builtins/x64/builtins-x64.cc` (Generate_CallFunction), `src/execution/arguments.h`, `src/interpreter/bytecode-generator.cc` (VisitCall).
- verify:
  - `cargo test --release --test browser -- js_conformance js_command_line jsdom_fixtures jsdom_gc_stress` → 0 (6 passed); `jsbench.py --smoke` → 0; `check_taste.py`, `check_layers.py` → 0.
  - `Math.abs` loop (5M calls): 1.07 → 0.93 s (P4.75s → this).
  - jsbench, base `c996cf8` → this, medians of 3, all checksums equal: array 1.17, calls 1.09, closures 1.12, crypto 0.96, dom 1.03, globals 0.98 (P4.75s alone measured 1.37 earlier: noise of this run), json 1.04, loop 1.00, methods 1.11, navier-stokes 0.96 (2.36 → 2.47 s), pixels 1.30, raytrace 1.31, richards 1.16, splay 1.09, strings 1.12, three 1.22, unicode-units 1.22; geomean 1.107. pixels/three vs P4.75s: within noise (1.91 vs 1.89–1.95 s; 3.82 vs 4.02 s).
