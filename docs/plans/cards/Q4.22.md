# Q4.22: the idle relayout of an animating page

- goal: Q4.21 ranked step 5 / cost 4: on mistral every idle animation frame runs `Ui_relayout` → `layoutShared` (736 ms per 10 s: `loadWebFonts` 291, `fillImagesWith` 297) and `layoutFrames` (256). Skip the font and image work when nothing they read changed, skip clean frames if that is cheap and safe, then find why every frame relays out and avoid the cause where that is safe.
- design:
  - Web fonts: `loadWebFonts` now says `FontLoad.Idle` (no face is wanted), `Waiting` (background loads run) or `Added`. `loadStyledWebFonts` (the three callers that have a `Styling`) keeps `Styling.fonts_settled`, the measurer's `webFontCount()` (new `Measurer` method: web fonts added plus failed) at the last Idle answer, and returns at once while the count is the same. The author sheet of a `Styling` does not change (a changed sheet source builds a new one), `FontFaceSet` in the prelude is a stub, so the faces are a function of the `Styling`; the count covers the measurer.
  - Images: `updateImages` returns early when `imagesAlreadyFilled`: the cache has no background load or decode running and its `ImageFillStamp` (taken after the last fill) equals the current one: DOM version minus `Script.image_neutral`, `Script.image_version`, `nodes.changes`, `ImageCache.landings` (decodes landed), `revealed.len()`, `Page.sheet_key`, viewport. `image_neutral` counts the writes that cannot change an image or a style URL, written by the same natives that move `Script.version`: `changedText` (text and comment data, `textContent` over text-only children) and `canvasChanged`. Every other writer keeps moving the relevant version, so an unlisted writer is conservative.
  - Same-text `textContent`: `sameTextChild` returns before any change when the element's only child is a Text with equal non-empty data and `Document.observed` is false (set by `MutationObserver.observe` through `ak.setObserved`; `recording` is on in every page for resource discovery, so it cannot be the test). Blink: `Node::setTextContent`, same condition with `MayHaveMutationObservers`. With an observer the node is replaced and the records are queued as before.
  - Not done: `layoutFrames` skipping clean frames. After the two skips above the whole `layout_frames` is 0.11 to 0.14 ms a relayout for 6 documents on the test page (0.20 to 0.27 before, of which fonts and images of the frames were most), and a skip needs a stamp over layout version, geometry changes, transitions, decodes, fonts and nested frames to be safe; not worth it for 0.1 ms.
  - Why every frame relays out: (a) the same-text write replaces the Text node and moves the DOM version; fixed above for pages without observers (restyle and `layout_dirty` go to 0). Mistral has observers on `BODY`, and Blink also replaces the node there, so the records and the version move; (b) an animating canvas in an iframe moves that document's version (`canvasChanged`), which makes the tab relay out and rebuild its display list (`paint_build`, 5 ms of the 6.5 to 7.2 ms a relayout left on the test page). That is Q4.18's left item (a paint-only path for canvas draws, damage for the canvas box), not done here.
- references:
  - `third_party/blink/renderer/core/dom/node.cc` (`Node::setTextContent`): identical single text child and no mutation observers: return. Dweller takes the same condition.
  - `third_party/blink/renderer/core/css/font_face_set_document.cc`: only faces whose state changed cause a style recalc. Dweller takes: a settled face set is not looked at again.
