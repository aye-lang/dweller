# P11.14e: WebGL conformance: early page deaths, compressed-texture validation, WebGL in workers

- goal: P11.14d's failure groups 2-5: (1) `successfullyParsed should be true` (52 pages): read each page's first `[error]`, fix the largest causes in the engine; (2) compressed-texture validation per each extension spec; (3) WebGL in dedicated workers (`transferControlToOffscreen`, OffscreenCanvas through `postMessage`, a GL context current on the worker thread, `commit()`/rAF presenting to the placeholder, `transferToImageBitmap`); (4) WebAssembly in the CTS run. Group 1 (timeouts from JS speed) belongs to another card.
- design:
  - Early deaths: 50 of the 52 pages died on a `TypeError: gl.X is not a function`; six WebGL methods were never written and the WebGL 1 context lacked a seventh. `webgl-more.js` adds `getUniform`, `copyTexImage2D`, `getFramebufferAttachmentParameter`, `getActiveUniforms`, `getActiveUniformBlockParameter` and `getUniformIndices`; one native, `webglMore(canvas, op, ...)` (`webgl-more.aye`), makes the GL call, raises a GL error into `getError` and returns `null` then, else the result words as an array (the JS side reinterprets them as float, int or uint).
    - `getUniform`: the location's type comes from the program's active uniforms (`name`, `name[i]` for arrays), cached per link; the value is a number, a bool, a typed array or an array of bools by type.
    - `getFramebufferAttachmentParameter`: the framebuffer remembers what `framebufferTexture2D`/`framebufferTextureLayer`/`framebufferRenderbuffer` attached (DEPTH_STENCIL to both), and `OBJECT_NAME` returns that object only while GL still reports its name (deleted objects detach). On the default framebuffer only BACK/DEPTH/STENCIL are accepted (INVALID_ENUM otherwise), mapped to the drawing buffer's attachments, and `OBJECT_TYPE` reads FRAMEBUFFER_DEFAULT.
    - The WebGL 1 `renderbufferStorage` called `this.renderbufferStorageMultisample`, which a WebGL 1 context does not have; `webgl1.js` calls the WebGL 2 one with 0 samples.
  - Compressed textures (`webgl-compressed-checks.js`, wrapping the P11.14d uploads):
    - WebGL 1: `level > 0` with a non-power-of-two width or height is INVALID_VALUE (`implied base mip 4x12 is invalid` in bptc and rgtc).
    - Each texture keeps the internal format of each compressed `(target, level)`; `compressedTexSubImage*` with another format is INVALID_OPERATION before the size check (`format does not match`, s3tc-and-rgtc).
  - WebAssembly: no engine change. `browser/build.sh` already links libwasmtime when `browser/wasm/fetch_wasmtime.sh` fetched it; the CTS binary must be built that way (see verify). All 6 `conformance2/wasm` pages pass.
  - WebGL in workers (not started; design for the next card):
    - Main thread: `HTMLCanvasElement.transferControlToOffscreen()` marks the canvas as a placeholder (later `getContext` throws InvalidStateError, a second transfer too) and returns an OffscreenCanvas holding the placeholder's id and size.
    - `engine/workers/wire.js`: an OffscreenCanvas is cloneable only in the transfer list; it encodes as `{t: 'C', id, w, h}` and the sender's object is detached (width/height 0, `getContext` throws). The worker decodes it to an OffscreenCanvas whose `_placeholder` is that id.
    - Worker canvas host: the worker `Interp` has no `__canvasHost`. `canvasBitmap(it, v)` looks bitmaps up through the page `Script`; it needs a per-Interp bitmap table so the worker scope (`installScope`) can install the WebGL natives without DOM nodes.
    - GL on the worker thread: `gpu` keeps the current EGL context in a global (`drawing_buffer.aye` `current`); it must be per thread, and each worker context makes itself current on its own thread (one EGLDisplay, ANGLE serialises with its global lock).
    - Present: `commit()` (and the worker's `requestAnimationFrame`, which runs callbacks on a 16 ms timer then commits) reads the drawing buffer into RGBA bytes and posts a frame `{id, w, h, bytes}` on the link's inbox; the main thread's inbox delivery writes it into the placeholder canvas's bitmap and invalidates paint.
    - `transferToImageBitmap()`: snapshot into an ImageBitmap, then clear the drawing buffer (as after a present with `preserveDrawingBuffer: false`).
- files: `browser/engine/webgl-more.{js,aye}`, `webgl-more-prelude.aye`, `webgl-compressed-checks.js`, `webgl-compressed-checks-prelude.aye`; wiring in `webgl_api.aye`, `script.aye`, `webgl1.js`, `browser/gpu/gl.aye` (eight GL entry points); `browser/tools/conformance/*` + `docs/conformance.md` (generated).
- reference: https://registry.khronos.org/webgl/specs/latest/2.0/#3.7.6 (getFramebufferAttachmentParameter on the default framebuffer), https://registry.khronos.org/webgl/specs/latest/1.0/#5.14.8 (compressed textures, level > 0 power of two in WebGL 1), https://registry.khronos.org/webgl/extensions/EXT_texture_compression_bptc/, https://html.spec.whatwg.org/multipage/canvas.html#dom-canvas-transfercontroltooffscreen; Blink (algorithm only): `modules/webgl/webgl_rendering_context_base.cc` (`ValidateTexFuncDimensions`, `ValidateCompressedTexFormat`), `core/html/canvas/html_canvas_element.cc` (`transferControlToOffscreen`), `core/offscreencanvas/offscreen_canvas.cc`.
