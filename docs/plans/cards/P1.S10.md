# P1.S10: zol's `tck` is a FingerprintJS hash of WebGL values from the machine; an archive's page has no WebGL (P1.S10b)

- goal: `page_load.py check --site zol` fails on main with 2 archive misses, both from mediav's `tck`. The zol archive was re-recorded 2026-11-25 02:27–02:31 (+08) by P1.S7, and the replays right after it passed. Find where `tck` comes from and make the replay deterministic at the source.
- method: `browser/build.sh` (safe) of main 888e29b7, and of 3593a439 (P1.S7's branch tip, which made the recording). The shared archive `target/sites/zol` of the main checkout, with no `DWELLER_PROFILE`. To see the page's own values, the archive was copied and the copy's `ssp_ad_sdk.js` was changed to request `https://fpjs.log/?<components>`; the replay prints that request as a miss. Two `DYLD_INSERT_LIBRARIES` shims, built in the scratchpad and not committed: one moves the real clock (`time`, `gettimeofday`, `clock_gettime`), one logs each `open`, `stat` and `getenv`.

## Where `tck` comes from

`W6(tid)` in `static.mediav.com/js/ssp_ad_sdk.js` (archive file `4145801495931476190.response`):

```js
[4,h6.load()] … [4,s.sent().get()] … r=s.sent(), o=G4(r.visitorId+t)   // t = tid "696"
i = cookie("__ad_cookie_mapping_tck_" + t)
i===o ? e(o) : (setTimeout(()=>e(""),3e3), (c=new Image).src=`…//ckmap.mediav.com/m?tid=${t}&tck=${o}`, c.onload=…)
```

- `h6` is FingerprintJS v4 (open source). It is bundled in the SDK. `visitorId` is `x64hash128` of the 41 sorted components, `key:JSON(value)` separated by `|`. `G4` is MD5. So `tck = md5(visitorId + "696")`.
- `show-g`'s `&tck=` is `W6`'s result. On the replay, the `ckmap` image is a miss, so `W6` gives `""` and `show-g` is requested without `tck`.
- The replay's components, from the changed copy: `canvas` (the winding, geometry and text images), `math`, `architecture 127`, `audio error` (no `createOscillator`), `dateTimeLocale error`, `timezone "UTC"`, `screenResolution [800,1280]`, `screenFrame [null,0,0,null]`, `hardwareConcurrency 4`, `languages [["en-US"],["en-US","en"]]`, `fonts []`, `fontPreferences` all 0, `touchSupport {0,true,false}`, `vendorFlavors []`, and fixed values for the others. A Node copy of `x64hash128` and MD5 of these components gives `f3db2380…`, which is the replay's value.

## P1.S10b: what a page reads from the machine

- goal: find the value the page reads from the machine's state, and make the replay independent of it.
- method: the build of main 773c1ae6 (`browser/build.sh`, safe), the worktree set up as `mac-setup.md` says (only `target/wasmtime` and `target/sites` linked). ## Fix

- Under `DWELLER_RECORD` or `DWELLER_REPLAY` a page has no WebGL: `ak.webglCreate` returns false before it opens ANGLE (`engine/webgl_api.aye`, `net.archived` in `browser/net/archived.aye`), so `getContext('webgl')` and `'webgl2'` give null, as with `DWELLER_GL=off`. A window or `dump` without an archive keeps WebGL on the real GPU.
- Why a fixed engine value, and why "no WebGL": it is one predicate and no new manifest field. It is the state the 19 other archives already pass in (this worktree, no ANGLE), so they stay valid. Values saved in the manifest cannot keep zol valid either: the old capture saved none, and its value is this Mac's GPU through Metal. SwiftShader would give fixed values but still needs ANGLE to be found from the working directory.
- Written in `browser/engine/PERF.md` ("Archive semantics"), `docs/webgl.md` §2, and the practice "A page loaded from an archive reads nothing from the machine" (`docs/practices/browser.md`).
- zol re-recorded 2026-11-25 05:43–05:48 (+08) after the fix (`page_load.py capture`, into a new directory, then moved to `target/sites/zol`; the old archive was kept as `target/sites-old-zol-20261125b` until the 20-site check passed, then deleted): 1060 requests, 131 s. The new archive has `ckmap…&tck=f3db2380…` and `show-g…&tck=f3db2380…`.

## Proof

- Test `net::archive_has_no_webgl` (`tests/browser/net.rs`, page `browser/tests/net/archive_no_webgl.html`): live on SwiftShader the page sees WebGL; it records with `DWELLER_GL=swiftshader` and replays with `swiftshader` and with `off`, by default and with `DWELLER_PROCESS=single`: the same output (`webgl off`), no miss. Before the fix (the engine change reverted): FAILED, `dump-default: webgl on-8192-9`. After: ok (14 s). `archive_` tests (5), `webgl::webgl_context`, `webgl::gpu_smoke`: ok.
- The 8 runs of the table above, after the fix: all `f3db2380…`.
- Record then replay of the new zol archive: 935 requests in the same order (the trace cuts a line at 512 bytes; the lines are compared as prefixes), the same Markdown, no miss.
- `check --site zol`: pass 3 times (`4/4` console errors), pass with `DWELLER_PROCESS=single`, pass with `DWELLER_GL=off`.
