# Q6.11b: WPT `url`, the URL setters

- goal: the `url-setters*.js` subtests (about 360 failing on `q6-11-url-idna`) pass. `class URL` in `engine/prelude.aye` rebuilt an href from its parts and reparsed it; the setters now run the URL Standard's basic URL parser with a state override.
- design:
  - the parser in `browser/url/` already had the override branches in its states (`scheme-state`, `host-state`, `port-state`, `path-start-state`, `file-host-state`, ...) but no entry point. New `pub fn setComponent(alloc, u, name, value)` (`set-component.aye`): `parserOfUrl` copies the `Url` into a `Parser` (reusing `copyAuthority`, `copyPath`, `copyQuery`, new `copyFragment`), `applyComponent` dispatches on `Component` (`component.aye`, `component-named.aye`), `runOverride` strips tab and newline (`cleanInput` without trimming), sets `state` and `override` and runs `runParser`, then `serializeUrl` writes the new href.
  - one file per setter: `set-protocol` (value + `:` through `SchemeStart`; the special/non-special, `file` with credentials or port and empty-host rules are `scheme-change-allowed`), `set-credential` (username and password, userinfo encode set, not on a URL without host, with an empty host or `file`: `cannot-have-credentials`), `set-host` (`Host` and `Hostname` states, not on an opaque path), `set-port` (empty string clears, else `Port` state), `set-pathname` (empties the path, `PathStart` state), `set-search` and `set-hash` (empty value removes the query or fragment and strips trailing spaces of an opaque path, `strip-opaque-trailing-spaces`; otherwise one leading `?` or `#` is removed and the `Query` or `Fragment` state runs).
  - a parse failure is not an error for the setter: the parser keeps what it had set before failing (`host` sets the host, then fails on a port above 65535, as the spec and WPT expect), so `runOverride` swallows `Invalid` and `serializeUrl` always runs. `OutOfMemory` propagates.
  - JS: native `ak.setUrlPart(href, part, value)` (`engine/ak-set-url-part.aye`) returns the parts array that `ak.parseUrl` returns (shared `urlPartsArray`, `engine/url-parts-array.aye`). `URL` setters call `_setPart`; `search` also reparses `searchParams`; `URLSearchParams._setSearch` uses `_setPart('search', ...)`. `<a>` and `<area>` setters already assigned through `URL` (`u[part] = v; setAttribute('href', u.href)`), so they share the path with no change.
- references: https://url.spec.whatwg.org/#concept-basic-url-parser , https://url.spec.whatwg.org/#urlutils-members . Read: `url/url_canon_stdurl.cc` and `third_party/blink/renderer/platform/weborigin/kurl.cc` (`KURL::SetHost`, `SetPort`, `SetPath`, `SetQuery`, `SetFragmentIdentifier`: the per-component canonicalizers on a parsed `Parsed` struct). Dweller takes only the idea of re-canonicalizing one component against the existing URL record; the algorithm is the spec's state override, not Blink's per-component replacement.
- files: new `browser/url/{component,component-named,set-component,apply-component,parser-of-url,copy-fragment,run-override,cannot-have-credentials,set-protocol,set-credential,set-host,set-port,set-pathname,set-search,set-hash,without-leading,strip-opaque-trailing-spaces}.aye`, `browser/url/set-component_test.aye`, `browser/engine/{ak-set-url-part,url-parts-array}.aye`; changed `browser/engine/{prelude,window_api}.aye`, `browser/url/URL.md`, `browser/tools/wpt_areas.json` (url threshold 88 -> 90), `browser/tools/conformance/{url.json,history.csv}`, `docs/conformance.md` (url row only).
