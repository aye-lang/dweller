# Q3.16d: the browser drops a `javascript:` URL aimed at a tab of another renderer

- goal: `window.open('javascript:...', name)` where `name` is a tab that another renderer hosts does nothing to that tab: its URL, its history and its document stay. With a renderer per tab and with one per site (the default). This is the first item of Q3.16c's Left.
- the hole (Q3.16c's Left): the source's renderer sends the URL to the browser as a `context` (ask 1, `navigateContext`), and `openTarget` (`ui/open-target.aye`) took it as any URL: it pushed it onto the tab's history and sent the tab's renderer a `navigate`. No renderer runs a `javascript:` URL that a `navigate` brings (`load` fetches it), so no script ran, but the tab's document was gone: the tab showed "Cannot load page", at `javascript:...`, history 2 of 2.
- the rule (Blink `LocalFrame::CanNavigate`, `third_party/blink/renderer/core/frame/local_frame.cc`; the browser side, `RenderFrameProxyHost::OpenURL` in `content/browser/renderer_host/render_frame_proxy_host.cc`): a `javascript:` navigation of another browsing context runs only if the source can access that context's document. A context in another renderer never is one, so the URL is dropped.

## As built

- `javascriptIntoOtherRenderer` (`ui/javascript-into-other-renderer.aye`): a `javascript:` URL whose context is a tab the sender opened (`openedTab`) that runs in another process (no renderer yet, or another pid; a same-site popup that shares the opener's process has the sender's pid). `openTarget` refuses it with the line `proxy_navigate` logs: `navigation refused: javascript:...`; nothing is pushed or sent.
- `openedTab` (`ui/opened-tab.aye`): the lookup half of `openedSlot`, which now calls it; a context with no tab yet (a new popup) is not refused here.
- `docs/process-model.md` §4: a `context` row says so. No IPC kind.
- no `DWELLER_TEST_EVIL` run: the renderer of `main` already sends this URL through `context`, so the plain run is the one that reaches the browser's check (the `javascript-url` hook rewrites only `proxy_navigate`).

## Tests

In `tab` and `site`:
