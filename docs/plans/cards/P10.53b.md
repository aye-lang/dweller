# P10.53b: CJK line breaking and white-space

- goal: `css/inline-text` toward its 60% threshold through line breaking of CJK text (UAX #14 classes with the CSS Text 3 `line-break` tailorings), then `word-break`/`overflow-wrap` layout and `white-space` as a shorthand.
- before: 3916/8083 (48.4%) on `p10-53-inline-text`.
- cause groups (failing before): `css-text/i18n` (~1080: CJ, IN, iteration marks, centered punctuation, CJK hyphens, PO/PR by `line-break` value and content language); `white-space` reftests and shorthand (~550); `word-break`/`overflow-wrap`/`line-break: anywhere` reftests (~300).
- design: `browser/tools/gen_line_break.py` writes `browser/layout/line-break-table.aye` (checked in, 610 ranges) from Unicode 15.1 `LineBreak.txt` and `EastAsianWidth.txt`: only the classes the rules use (OP CL CP NS EX IS IN PO PR BA HY GL QU CJ ID; EB/EM as ID); PO/PR with East Asian Width A/F/W are `PO_WIDE`/`PR_WIDE`; everything else is `XX`. `breaksBetween(a, b, rules)` still only breaks inside a word when one side is wide (English unchanged), then applies the pair rules: no break after OP, GL, PR (before letters), opening quotes; none before CL CP IS GL HY, closing quotes, NS, PO (after letters); CJ breaks unless `line-break: strict` or `word-break: keep-all|auto-phrase`; IN, iteration marks and `‐ –` after ID only with `loose`; `〜 ゠` with `normal|loose` in Chinese or Japanese; centered punctuation, wide PO before ID and wide PR before ID with `loose` in Chinese or Japanese. The content language is the nearest `lang` attribute (`contentLang`). `word-break: break-all` treats `XX` as ID.
- files: new `browser/layout/line-break-class.aye`, `line-break-range.aye`, `line-break-table.aye` (generated), `line-break-class-of.aye`, `break-rules.aye`, `break-rules-of.aye`, `content-lang.aye`, `breaks-after.aye`, `breaks-before.aye`, `breaks-before-nonstarter.aye`, `is-initial-quote.aye`, `browser/tools/gen_line_break.py`; `linebreak.aye` rewritten; `inline.aye` (wiring), `check_taste.py` (the table is generated).
- reference: https://www.unicode.org/reports/tr14/, https://drafts.csswg.org/css-text-3/#line-break-property, Blink `platform/text/text_break_iterator.cc` (algorithm only).
- golden: `browser/tests/layout/cjk_breaks.layout`: "あいうえおかティ" now breaks before the small kana ィ (CJ may start a line with `line-break: auto|normal`); the only change.
