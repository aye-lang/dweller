# P10.49: css/selectors to its threshold

- goal: WPT `css/selectors` to its 80% threshold; `:is`/`:where`/`:not`/`:has`, `:nth-child(of S)` and `:heading` parse, serialize and match as Selectors 4/5 say.
- before: on `train-1` (`wpt.py run css/selectors -j 4`) 4363/6277 (69.5%). The 1323/3342 row in `history.csv` was measured on an older test set.
- cause groups (failing subtests before):
  - `selectorText` and `insertRule` (about 430, all of `css/selectors/parsing/*` that use `test_valid_selector`): `sheet.cssRules` was a new array on every read, so the list a test held never saw `insertRule`; `insertRule` took rules with invalid selectors; `selectorText` was the source text, not the canonical serialization; rules with invalid selectors stayed in a `<style>`'s `cssRules`.
  - `:heading` / `:heading(n, ...)` unsupported (about 240: `heading.html` 182, `parse-heading` 28, `heading-pseudo-class-in-has*`).
  - An+B (104, `parse-anplusb`): `N- 123` read as invalid, `n-+1` and `2n 1` read as valid (the tokenizer dropped a number's explicit `+`).
  - namespaces (about 80): `*|*`, `*|E`, `|E`, `[*|att]`, `[|att]` were invalid.
  - `:state()` took any argument (11).
  - iframe globals (about 600, `attribute-case/semantics` and `syntax`): the tests read `global.mode` and call `global.getComputedStyle` on an iframe's window, which runs in its own engine (not done here).
- design: `css.selectorText` (`browser/css/selector-text.aye` and the `write-*` files) serializes a selector list from its tokens per CSSOM: whitespace collapsed, combinators and commas spaced, `*` and `*|` dropped where the spec drops them, identifiers and strings escaped, attribute values quoted, case flags and pseudo names lower-cased, legacy `:before` as `::before`, An+B canonical (`writeAnPlusB`), `:is()`/`:not()`/`:has()`/`of S` arguments recursively. `ak.selectorText` (`engine/ak-selector-text.aye`) returns it, or null when `parseSelector` rejects the selector. The prelude's `CSSStyleSheet` keeps one live `cssRules` array (`_syncRules` after each change), drops rules with invalid selectors from a `<style>`'s text (`validRule`), throws `SyntaxError` from `insertRule` for them, and gives `selectorText` the canonical form. `:heading` is `SelKind.Heading` (`h1`–`h6`); `:heading(list)` keeps the listed levels as a bit mask (`headingLevels`, integers only) and `headingMatches` tests the tag's level (no `headingoffset`). The tokenizer marks a number written with `+` (`text = "+"`), so `parseAnPlusB` knows a signed B. `*|` before a type is any namespace; `|E` never matches an HTML element; `[*|a]` and `[|a]` are `[a]`.
- files: `browser/css/` (new: `selector-text`, `write-selector-list`, `write-complex`, `compound-end`, `write-compound`, `type-part-end`, `write-type-part`, `write-attribute`, `write-pseudo`, `write-pseudo-args`, `write-an-plus-b`, `write-ident`, `write-lower-ident`, `write-css-string`, `write-hex`, `write-selector-token`, `is-delim-tok`, `heading-levels`, `heading-matches`; `selector.aye`, `tokenizer.aye`), `browser/engine/ak-selector-text.aye`, `window_api.aye` (registration), `prelude.aye` (`CSSStyleSheet`).
- reference: https://drafts.csswg.org/cssom/#serializing-selectors, https://drafts.csswg.org/css-syntax-3/#serializing-anb, https://drafts.csswg.org/selectors-5/#headings; chromium `third_party/blink/renderer/core/css/css_selector.cc` (`SelectorText`), `css_selector_parser.cc`, algorithm only.
- verify: `python3 browser/tools/conformance.py run css/selectors`; `python3 browser/tools/conformance.py check; echo $?` → 0; `cargo test --release --test browser -- style_fixtures layout_fixtures jsdom_fixtures errors > /tmp/a.log 2>&1; echo $?` → 0 (no golden changed); `check_taste.py`, `check_layers.py` → 0.
- status: done 2026-10-17. `css/selectors` 4363/6277 (69.5%) → 5023/6277 (80.0%, threshold 80); no file lost subtests. Largest gains: `heading.html` +182, `parse-anplusb` +88, `attribute-case/syntax` +53, `-semantics` +30, `parse-has` +29, `parse-heading` +28, `parse-is-where` +27.
- left (largest first): iframe windows' globals and `getComputedStyle` across engines (about 550 in `attribute-case`), setting `selectorText` and `insertRule` on `CSSMediaRule` (`attribute-case/cssom` 64), `:focus-visible` tests that time out on mouse focus (about 75), `:has-slotted()` and class-prefix `.foo-*` (tentative, about 90), `CSS.supports(selector())` for selectors valid only through forgiving parsing (about 25), custom properties in `getComputedStyle` (`not-specificity`, `has-specificity` 16), `::part()`/`::slotted()` validity rules (about 15), `:dir()` on inputs and `dir=auto` (28), `headingoffset`, `:active`/`:open`/`:modal` invalidation.
