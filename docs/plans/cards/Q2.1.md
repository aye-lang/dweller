# Q2.1: design note for the process model and site isolation

- goal: one note, `docs/process-model.md`, that Q2.2–Q2.14 implement: what the browser and the renderers own and where each module goes; the IPC (transport, framing, the messages by group); the site and the process reuse policy; the site-lock checks per message and the kill; compositing and hit testing of out-of-process iframes; the sandbox per OS; crash, hang and session restore; how Spaces become renderers; the risks ranked, and the changes to the Q2 step list.
- cause: the decision of 2026-11-04 (full site isolation, as Chromium and Firefox Fission) reverses "no process per site" of 2026-10-15. Fourteen steps build on it, so the design is fixed once, before code.
- design (the choices; the reasons are in the note):
  - Binary IPC over the Spaces transport (`posix_spawnp`, one `socketpair` per renderer), buffers and fds by `SCM_RIGHTS`, frames acked. Only a renderer makes sync calls, and the browser answers them from its own state, so no deadlock. An IO thread wakes the browser's SDL loop.
  - Site = scheme + registrable domain from `net/psl.aye` (port ignored). One process per site in a browsing context group (a rule); OOPIFs reuse any same-site process; new tabs get a new process under a soft cap of Chromium's formula, and over it a random same-site one.
  - The browser fills in or checks every origin a renderer states (Chromium's `CanAccessDataForOrigin` jail check); a failed check kills the renderer. Each step adds the checks of its own messages; Q2.7 audits the table and adds a compromised-renderer test hook.
  - The window composes a tab from each local root's buffer, its remote children (rect, clip, opacity) and an "over" buffer for parent content above a child; hit testing in the browser, with the parent renderer asked when a child is transformed or covered.
  - Spaces become agent-owned tab groups in the browser, their frames in ordinary renderers; the jar copy of `ui/share-with-space.aye` goes; refs stay as they are (the browser renumbers).
  - Step list: add Q2.1b (split `ui/window.aye` in one process first) and Q2.3b (agent commands to renderers); split Q2.6 (navigation and history in the browser, then the process swap) and Q2.8 (macOS, Linux); move Q2.8 before Q2.6; checks land with their messages.
- files: `docs/process-model.md` (new), `docs/plans/cards/Q2.1.md` (new)
- chromium: `docs/process_model_and_site_isolation.md` (locks, reuse, special cases: taken as is), `docs/security/compromised-renderers.md` (what a compromised renderer must not get: the §4 table), `content/browser/site_info.cc` `GetSiteForOrigin` (site = scheme + eTLD+1 with private registries, no port), `content/browser/child_process_security_policy_impl.cc` `CanAccessDataForOrigin` (the jail check), `content/browser/renderer_host/render_frame_proxy_host.{h,cc}` `RouteMessageEvent` (postMessage: kill on a bad source origin, drop on a target origin race), `third_party/blink/renderer/core/frame/remote_frame.cc` (what a proxy carries), `content/browser/renderer_host/render_process_host_impl.cc` `GetMaxRendererProcessCount` (the cap formula), `sandbox/policy/mac/renderer.sb` and `common.sb` (the seatbelt profile shape).
