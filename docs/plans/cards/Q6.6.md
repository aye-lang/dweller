# Q6.6: WPT `css/cascade-variables` to threshold

- goal: the area (`css/css-cascade`, `css/css-variables`) reaches its floor of 75 plus 2 points (56.1 in the table; 794/1436, 55.3%, measured at the start of this card). One cause per cluster, largest first.
- design (clusters in the order done; subtests are of the area's 1436):
  - `getComputedStyle(el).getPropertyValue('--x')` answered nothing: there was no path from the cascade's `CustomLevel` to script. `css.customText` (custom-text.aye) looks the name up in the element's level and writes the substituted tokens; `engine/computed-custom.aye` picks the styles the computed values came from. A whitespace token keeps its source text (`tokenizer.aye`, `write-space.aye`), an empty value is a valid declaration (`parser.aye`) and `--` alone is not a name. 794 -> 841.
  - cycles and CSS-wide keywords (vars.aye, `mark-cycle.aye`, `custom-keyword.aye`, `custom-beats.aye`, `visit-fallback.aye`, `trimmed-tokens.aye`): every member of a `var()` cycle is invalid (an intrusive stack of the variables being resolved; an unused fallback is still an edge), and a value that is `initial`, `inherit`, `unset`, `revert` or `revert-layer`, also after substitution, means that keyword. 841 -> 867.
  - the inline style was read by splitting on `;`: `engine/style-value.aye` now walks declarations (`next-style-decl.aye`, `decl-end.aye`: strings, blocks, escapes), splits `!important` (`split-important.aye`), compares custom names with case, lets an important declaration stand against a later normal one and answers "" for a longhand of a shorthand with `var()` (`reads-decl.aye`, `css/shorthand-covers.aye`). `var()` arguments follow css-values-5: any non-empty name argument without a mixed `{}` block (`css/valid-var-text.aye`, `valid-vars.aye`, `valid-var-args.aye`, `has-top-brace.aye`). 867 -> 892.
  - a `style` element fires `load` when a script connects it (`styleDiscover` in prelude.aye): `import-conditions`, `layer-import`, `layer-statement-before-import` timed out waiting for it. 892 -> 941.
  - CSSOM rules were plain records with the source text: `engine/cssom-syntax.js` and `cssom-rules.js` (embedded by `cssom-rules-prelude.aye`) give `CSSRule` and its subclasses (`CSSStyleRule`, `CSSGroupingRule`, `CSSConditionRule`, `CSSMediaRule`, `CSSSupportsRule`, `CSSContainerRule`, `CSSScopeRule`, `CSSLayerBlockRule`, `CSSLayerStatementRule`, `CSSImportRule`, `CSSNestedDeclarations` and the others by name), nested `cssRules` with `insertRule`/`deleteRule`, `selectorText` and `style` that write back to the sheet (`_ruleChanged` replaces the top-level rule's text), stable rule objects, `cssRules.item`, canonical `cssText` (`ak.declarationsText`: `engine/declarations-text.aye`, `append-canonical-decl.aye`, `css/known-property.aye`), and validity of `@scope` preludes and `@layer` names. 941 -> 1033.
  - `var(var(--x))`: the name argument is substituted, then read as a name (`css/var-name.aye`, `top-comma.aye`); `all` accepts only CSS-wide keywords inline; an empty custom value serializes as one space, as the tests of this revision expect. 1033 -> 1071.
  - `supports()` functions `font-format()`, `font-tech()`, `at-rule()` and `!important` in a declaration test (`css/supports-function.aye`, `without-important.aye`); `@keyframes` of the same name are ordered by cascade layer (`Keyframe.layer`, `engine/last-keyframes-rule.aye`); `style.cssText` is serialized as a declaration block, a declaration a later one overrides left out (`engine/format-style-text.aye`, `overridden-later.aye`, `append-formatted-decl.aye`). 1071 -> 1085.
  - `style.getPropertyPriority`, `style.item` and the priority argument of `setProperty` (`engine/style-priority.aye`, `style-get-property-priority.aye`, `style-item.aye`, `make-important.aye`). 1085 -> 1089.
  - `revert` and `revert-layer` did not exist (the declaration was dropped at parse). They parse as CSS-wide keywords (`Decl.reverts`). The cascade keeps, per property, the best declaration of a lower origin-and-layer group and the best user-agent one (`css/track-rollback.aye`, `win-group.aye`), only once an element offered such a declaration: that element is then matched again with tracking on (`match-with-rollback.aye`, `enable-rollback.aye`), so pages without the keywords pay one branch per offer. `rolled-back.aye` and `rollback-value.aye` resolve the keyword; a chain deeper than one step ends in `unset`. 1089 -> 1116.
- decisions taken without asking (plan defaults):
  - `style.cssText` no longer echoes the attribute: it is the serialized block (names in lower case, `name: value;`). Unknown properties are kept there (a page that appends to `cssText` loses nothing); only a rule's `cssText` drops what does not parse.
  - A script-connected `style` element always fires `load`, never `error` (a failed `@import` should give `error`).
  - `font-tech()` answers true for `features-opentype`, `variations`, `color-colrv0`, `color-colrv1`, `palettes`.
