# Q4.25c: records for the criterion with a renderer per site

- goal: the criterion Q4.25's card proposes has a command: with `DWELLER_PROCESS=site`, the time from an input to the renderer's frame that holds it, each renderer task, and the idle CPU of the window and its renderers together; `window_perf.py report --replay` prints them per site.
- source: `docs/plans/cards/Q4.25.md` (d), row Q4.25c of `foundations.md`.
- design:
  - window: `TabProcess.input_ns` and `input_kind`. Each input the window sends a renderer (`sendMouse`, `forwardWheel`, `bubbleScroll`, `forwardKey`, `forwardEdit`, `forwardTab`) starts the clock when none runs (`noteInputSent`, kinds `wheel`, `click` for a button down or up, `move`, `key`). The renderer acks an input after it sent the frame that holds it, so `input_ack` ends the record (`noteInputAcked`, in `rendererSent` and `childSent`): `DWELLER_TIMING input_to_frame NS KIND`. When inputs are still open after an ack the clock starts again there, so a burst gives one record per ack, the first from the oldest input.
  - renderer: `serveTabs` writes `r_task NS PID` for each turn of its loop that handled messages (`answerAll`) or ran timers (`runAllTimers`): `noteTask`, the label is the renderer's pid.
  - `window_perf.py scroll` prints `input_to_frame_n_p50_p95` (all kinds but `move`) and `renderer_longest_task_ms` (the longest `r_task`). `idle` sums the CPU of the window and every process under it (`ps -A -o pid=,ppid=,time=`): `idle_cpu_pct` is now that sum, `window_cpu_pct` the window alone, `renderers` the number of processes under it.
  - `window_perf.py report --replay --process site` (or `tab`) runs each site with `DWELLER_PROCESS` set and the step `renderer:loaded wheel:-3 renderer:input`, and judges Q4.25's criterion: the window's longest loop under 100 ms, wheel to frame p95 under 33 ms, idle CPU of all under 5%; it also prints the renderer's longest task.
- files: new `browser/ui/{note-input-sent,note-input-acked,mouse-kind-name}.aye`, `browser/ui/{tab-process,send-mouse,forward-wheel,bubble-scroll,forward-key,forward-edit,forward-tab,renderer-sent,child-sent}.aye`; new `browser/renderer/note-task.aye`, `browser/renderer/serve-tabs.aye`; `browser/tools/{window_perf,window_report}.py`; new `tests/browser/window_renderer_perf.rs` (and its `mod` pair).
