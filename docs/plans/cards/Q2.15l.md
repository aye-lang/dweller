# Q2.15l: `rootBounds` for a cross-origin target

- goal: fifth item of the lane's second list [Q2.10 Left: in a child, "`rootBounds` is the child's own viewport (it should be null for a cross-origin target), `rootMargin` applies to the child's viewport"]. An `IntersectionObserver` with the implicit root told a cross-origin frame the size of a viewport, and let its `rootMargin` grow it.
- design: `ak.topCrossOrigin()` (`engine/ak-top-cross-origin.aye`): the script's document is in a cross-site frame's renderer (it has a visible rect from its embedder) or is a frame that is not same-origin with the page at the top of its renderer. For such a target and the implicit root, `_entry` (prelude) does not apply `rootMargin` and gives `rootBounds: null`; everything else (the intersection with the frame's own viewport and with the rect its embedder says is visible) is unchanged. An explicit `root` element is not affected.
- spec read: https://w3c.github.io/IntersectionObserver/#dom-intersectionobserverentry-rootbounds ("If target is not in the same origin-domain as the top-level document, rootBounds is null") and #intersectionobserver-root-intersection-rectangle (the root margin is only applied for a same-origin-domain target). Chromium: `third_party/blink/renderer/core/intersection_observer/intersection_geometry.cc` (`ShouldReportRootBounds`, `RootIsImplicit` with `ApplyRootMargin` only when the frames are same origin).
- files: new `browser/engine/ak-top-cross-origin.aye`, `browser/engine/window_api.aye` (the registry line), `browser/engine/prelude.aye` (`_entry`: 3 lines); new `browser/tests/ui/{oopif-root,oopif-root-child}.html`; `tests/browser/window_renderer_limits.rs`.
- verify (2026-11-19, Linux x86_64): `window_renderer_limits_root_bounds`, in the window's process and with `DWELLER_PROCESS=site`: `oopif-root.html` (the page observes its own element, its `localhost` frame observes one and posts what it got): the page's title is `P own rect W frame null true` (the page's own entry has a rect, the frame's `rootBounds` is null and it intersects). `window_renderer_oopif_input_intersection` (Q2.10) passes unchanged.
