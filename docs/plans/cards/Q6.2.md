# Q6.2: WPT `css/css-grid`, grid value syntax, shorthands and resolved track lists

- goal: `css/css-grid` goes from 43.2% toward its threshold (60). Slice 1 takes the clusters with one cause each in `parsing/` and `grid-definition/`: grid values were `Raw` text that was never validated, the shorthands `grid`, `grid-template`, `grid-row`, `grid-column`, `grid-area` were not expanded in `style.*`, and `getComputedStyle` dropped line names and implicit tracks.
- design:
  - validation in `browser/css/` (called from `parseValue` for `PKind.Raw` grid properties, so stylesheets, `@supports` and CSSOM all agree): `is-grid-value` dispatches to `is-track-list` (`scan-tracks`/`scan-track`/`scan-repeat`: line names, `repeat()`, one auto-repeat whose tracks and the others are fixed-size), `is-track-size`/`is-minmax`/`is-track-breadth`/`is-length-percentage`, `is-grid-line` (span at either end, no 0, no negative span), `is-grid-areas`, `is-grid-auto-flow`.
  - shorthands: `grid-lines` check in `gridLines`; `grid-shorthand` (the three `grid` forms, `auto-flow-prefix`, `grid-auto-side`, `grid-flow-keyword`); `grid-template-areas-form` (the `"a b" 10px / cols` form, previously dropped); `shorthandLonghands` lists the right longhands for `grid`, `grid-row`, `grid-column`.
  - CSSOM: `specifiedValue` rejects invalid grid declarations (`checks-grid`, reusing `parsesAs`, shorthands included); `styleValue` in `engine/dom_api.aye` falls back to `longhand-from-shorthands` so `style.gridColumnEnd` reads after `style.gridArea = ...`.
  - resolved values (`engine/write-resolved.aye`): `write-resolved-tracks` rebuilds the track list with line names, expanded `repeat()` and implicit tracks (`flatten-tracks`, `flatten-repeat`, `auto-repeat-count`), and `canonical-areas` normalizes `grid-template-areas` (single spaces, dot runs as one `.`).
- references: https://drafts.csswg.org/css-grid-2/#track-sizing , #resolved-track-list , #propdef-grid . Chromium `third_party/blink/renderer/core/css/parser/css_parsing_utils.cc` (`ConsumeGridTrackList`, `ConsumeGridLine`) and `grid_track_list.cc`; `grid_layout_algorithm.cc` / `grid_track_sizing_algorithm.cc` were read for the sizing side, not yet used. Dweller takes the track-list grammar (auto-repeat rules, fixed-size, line-name adjacency) and the `ComputedStyle` resolved-value shape (names kept, repeat expanded).
