# P10.55b: ch and ex from the font; @font-face in script geometry

- goal: `ch` and `ex` resolve from the first available family's `0` advance and x-height (Ahem: 1em, 0.8em; fallback 0.5em when unavailable), not fixed 0.5em; testharness tests (`dweller wpt`) that load a web font measure script geometry with it.
- reference: https://drafts.csswg.org/css-values-4/#font-relative-lengths; blink `core/css/css_to_length_conversion_data.cc`, `platform/fonts/font_metrics.cc` (algorithm only).
- design: `css.Value` keeps `Ch` and `Ex` (parse: `values.aye lengthValue`). The cascade resolves them in `absolute`, and math functions in `calc.aye unitPx`, through `currentFontUnits()`: `computeValues` sets the source (`useFontUnits`: the parent's font for `font-size`, then the element's own; `dropFontUnits` at the end; outside the cascade 0.5em), and the px come lazily, once per element, from `fontUnitsOf` (family, weight, style; a value not computed yet is the parent's), which calls a hook (`setFontUnitsHook`) so css imports no font state. The engine sets the hook (`setDefaultMeasure`, and `useUnitsMeasure` at the start of `layoutPage`); `measureFontUnits` takes the window's measurer, else the default one, and gives `width("0")` (when the font has a `0`) and `metrics.x_height`; 0 means unavailable (0.5em). `layout/grid.aye` resolves track `ch`/`ex` with `fontUnitsOf` of the box style, only when a track uses them. `getComputedStyle` gives px. With `font.Fixed` (layout fixtures) ch = ex = 0.5em as before. Script geometry in `dweller wpt` loads the `@font-face` faces into the default measurer (`loadScriptFonts`, before styling in `layoutGeometry`; a font added drops the geometry so styles and layout are done again).
- files: new `css/font-units.aye`, `css/set-font-units-hook.aye`, `css/font-units-of.aye`, `css/use-font-units.aye`, `css/current-font-units.aye`, `engine/use-units-measure.aye`, `engine/measure-font-units.aye`, `engine/load-script-fonts.aye`; wiring in `css/css.aye`, `css/values.aye`, `css/calc.aye`, `css/cascade.aye`, `css/layers.aye`, `css/zero-as-px.aye`, `layout/grid.aye`, `engine/engine.aye`, `engine/geometry.aye`, `engine/set-default-measure.aye`.
