# P10.53c: emergency breaks, word-break, white-space shorthand

- goal: `css/inline-text` toward its 60% threshold, and long URLs and words that do not overflow their column: emergency breaks for `overflow-wrap: break-word|anywhere` and `word-break: break-word`, `word-break: keep-all`, `white-space` as a shorthand, breaks across inline box boundaries (P10.53b's "left" list).
- before: 4580/8083 (56.7%) on `p10-53b-cjk-breaks`.
- design:
  - emergency breaks: when a chunk does not fit on an empty line, `splitOverflow` finds the first word piece that overflows and, if `emergencyWrap` allows (`overflow-wrap: break-word|anywhere` or `word-break: break-word`, and the text wraps), `splitWord` cuts it at the last grapheme boundary that fits (at least one grapheme) and inserts the rest as a new piece; the line loop then runs again on the shorter chunk. A word goes to the next line before it is broken (no break while the line has content). `anywhere` and `word-break: break-word` (`wrapsMinContent`) lower min-content to the widest grapheme of the word. Graphemes are a code point plus following zero-width code points (`nextGrapheme`).
  - `word-break: keep-all`: no break between two letters (ID or the unlisted classes, `keepsLetters`); when such a word overflows an empty line, the restriction is relaxed (`relaxesKeepAll`, split as an emergency break when the word starts with a wide character). `word-break: break-all` was already done by P10.53b (`XX` as ID).
  - `white-space` is a shorthand of `white-space-collapse` and `text-wrap-mode` (no longer a longhand in `PROPERTIES`): `normal | pre | pre-wrap | pre-line` map to pairs, anything else is `<white-space-collapse> || <text-wrap-mode>` (`anyOrder`). Specified and computed values serialize to the shortest form (`normal`, `nowrap`, `pre`, `pre-wrap`, `pre-line`, else `collapse [nowrap]`). Layout reads `white-space-collapse` (`preserve-spaces` keeps spaces but not newlines).
  - inline box boundaries: the collector remembers the last code point of the previous word (`last`, reset by spaces, breaks, atomics) and marks the previous word soft when `breaksBetween(last, first)` holds at the start of the next text box.
