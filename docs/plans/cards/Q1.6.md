# Q1.6: jsdom_gc_stress is one test again, with every jsdom fixture

- goal: GC stress (`DWELLER_JS_GC=stress`, a collection at every allocation) runs every jsdom fixture, `focus_freed` and `gc_wrappers` too, as one test that takes well under 10 min on CI.
- cause: `focus_freed.html` (8a06375) made about 900,000 values (300,000 kept objects with 300,000 strings, then 300,000 more objects) so that the collector freed a removed focused node. Under stress the kept array made that quadratic: hours, so 33f6344 left it out of the stress run with `gc_wrappers`. TC3e then split the test into four parts because it took 908 s on Ubuntu. The parts are fast now: in `main` runs 41744155535 and 41733950452 they took 23 to 88 s each, 151 to 247 s together on Ubuntu and 192 to 206 s on macOS.
- design:
  - `focus_freed.html`: the two loops become one loop of 40,000 short-lived objects, twice the 20,000 allocations after which the collector runs (`js/gc.aye`). Measured with the fix reverted, normal mode: the collection comes at 19,979 allocations after a fresh collection, so 40,000 always frees the node (threshold max(20000, 2 × live); live is under 10,000 here). `.tree` updated for the new script text.
  - `tests/browser.rs`: `jsdom_gc_stress` is one `#[test]` again (the body of before TC3e) without the `HEAVY` list, so it runs all 112 fixtures and `run.jsonl`.
  - `tests/browser-times.txt`: the four `jsdom_gc_stress_N` lines become one `jsdom_gc_stress` line with the times of the PR's first `ci` run (41748679830).
- files: `browser/tests/jsdom/focus_freed.html`, `browser/tests/jsdom/focus_freed.tree`, `tests/browser.rs`, `tests/browser-times.txt`, `docs/plans/cards/Q1.6.md` (new)
- verify: with 8a06375's fix reverted the stress run of `focus_freed` fails, with it it passes; `scripts/capped.sh env AYE=$AYE cargo test --release --test browser -- jsdom_gc_stress` exit 0; `python3 browser/tools/check_taste.py` exit 0; on CI the PR's `ci` run is green and `jsdom_gc_stress` takes under 10 min.
