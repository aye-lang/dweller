# Q3.9: iframe `sandbox`, every token

- goal: the `sandbox` attribute parses into the spec's sandboxing flag set, frames inherit it, and the in-process mode enforces scripts, origin, forms, popups, top navigation and modals. WPT `html/browsers/sandboxing` becomes a measured area.
- design:
  - `browser/engine/sandbox-flags.aye`: the 18 flags of the spec as `SB_*` bits. `parseSandbox` (`parse-sandbox.aye`) starts from `SB_ALL`, splits on ASCII whitespace and clears the flags of each token (`sandbox-token-flags.aye`, ASCII case-insensitive; unknown tokens ignored). `allow-top-navigation` clears both top-navigation flags, `allow-top-navigation-by-user-activation` only the by-activation one, `allow-scripts` clears scripts and automatic features. CSP `sandbox` (Q3.8) can call the same `parseSandbox`.
  - `Page.sandbox: u32`: `placeFrame` sets it to the parent's flags plus the iframe's attribute, read when the frame navigates. `no_scripts` and `opaque` derive from it.
  - enforcement: `dispatchSubmit` returns false and `submitForm` null without `allow-forms`; `window.open` returns null for a new or named context without `allow-popups`; `sandboxAllowsNavigation` (spec "allowed by sandboxing to navigate") gates `window.open` into `_top`/`_parent`/a named frame and the `Location` setters of another window (`SecurityError`); `alert`/`confirm`/`prompt` do nothing without `allow-modals`; `document.cookie` and Web Storage throw `SecurityError` without `allow-same-origin`.
  - parsed and stored, nothing to block yet: `allow-downloads`, `allow-pointer-lock`, `allow-presentation`, `allow-orientation-lock`, `allow-storage-access-by-user-activation`, `allow-top-navigation-to-custom-protocols`, `allow-popups-to-escape-sandbox` (see Left).
- references: https://html.spec.whatwg.org/multipage/browsers.html#sandboxing , https://html.spec.whatwg.org/multipage/browsing-the-web.html#allowed-by-sandboxing-to-navigate . Read: `third_party/blink/renderer/core/frame/sandbox_flags.cc` (token table, whitespace split, unknown tokens reported and ignored; algorithm only), `services/network/public/mojom/web_sandbox_flags.mojom` (flag list).
- files: new `browser/engine/{sandbox-flags,sandbox-token-flags,parse-sandbox,parse-sandbox_test,sandbox-allows-navigation}.aye`, `browser/tests/jsdom/sandbox_flags.{html,tree,err}`, `browser/tools/conformance/html_browsers_sandboxing.json`; changed `browser/engine/{engine,frames,forms,dispatch-submit,window_api,windows,storage}.aye`, `browser/tools/{wpt_areas.json,conformance/history.csv}`, `docs/conformance.md`.

## Status: done, 2026-11-08

Left:
- Tab mode (`DWELLER_PROCESS=tab`, #331/#334): the browser-side navigation must check the initiator's flags for top navigation, popups and form targets; the renderer does not send them yet.
- Popups do not inherit the opener's flags (`SB_PROPAGATES_TO_POPUPS` is stored, `openContext` takes no flags), so `allow-popups-to-escape-sandbox` changes nothing yet. WPT `sandbox-popup-inherits-script-blocking`, `sandbox-disallow-scripts-via-unsandboxed-popup`, `sandbox-window-open-srcdoc` fail on this.
- Link and form targets (`_top`, `_parent`, named frames, `_blank`) clicked by the user go through `ui/` and `targetFrame`, which do not check `sandboxAllowsNavigation` or `allow-popups`. Script navigations pass `activated = false` (transient activation is Q3.14c, unmerged), so `allow-top-navigation-by-user-activation` never allows a script's top navigation.
- `localStorage` throws on use, not on access of the property itself; `sessionStorage` the same.
- WPT failures not yet looked at: `sandbox-disallow-popups` (0/1), `sandbox-allow-scripts` (ERROR), `sandbox-inherited-from-*` (initiator and CSP inheritance), `sandbox-document-open`, `sandbox-javascript-window-open` (timeouts).
- No feature to gate: downloads, pointer lock, presentation, orientation lock, storage access, custom-protocol navigation, plugins, `document.domain`.
- Tooling: an upstream WPT run that ends leaves `wpt serve` children holding 8000/8001/8443/8444, and the next run then fails with "cannot connect" on every file; this card killed them by hand.
