# P10.51: CSS Animations: @keyframes and the animation-* longhands

- goal: CSS Animations (https://drafts.csswg.org/css-animations-1/): `@keyframes` in the cascade, the `animation-*` longhands and the `animation` shorthand, running animations sampled through P10.47's `interpolateText`, the animation events, `getAnimations()` returning `CSSAnimation` objects on the Web Animations machinery, and `getComputedStyle` showing the animated value. The CSS Animations quarter of every `*-interpolation.html` failed on it (P10.47).
- design:
  - Cascade: `@keyframes` / `@-webkit-keyframes` (top level only) parse into `Sheet.keyframes`: one `Keyframe` per selector offset (`from`, `to`, `0%`–`100%`; a block with an invalid selector is dropped) with the declarations of its block (`Parser.declarations`, kept out of every `Rule`), and the index of its rule (`Sheet.keyframe_rules`); an empty rule still gets one entry with no declarations. The name is an identifier other than `none` and the CSS-wide keywords, or a string. `lastKeyframesRule` picks the last rule with a name (last wins); `!important` declarations in keyframes are dropped (`pushKeyframe`).
  - Longhands (`PROPERTIES`, P10.48): `animation-name`, `-duration`, `-timing-function`, `-delay`, `-iteration-count`, `-direction`, `-fill-mode`, `-play-state`, `-composition` (parsed; composition acts as `replace`). Comma lists as for transitions (`transitionList` → `writeAnimationItem`). The `animation` shorthand (`addAnimation`, `writeSingleAnimation`, `animationSlot`: each component goes to the first free longhand that accepts it, the name last); the computed `animation` serializes the shortest form (`writeAnimation`, the duration kept when the delay is set, `none` when all are initial). `cubic-bezier()` now serializes with 6 significant digits (`appendFloat`, as Blink), which the harness's `createEasing` needs.
  - Runtime (`engine/css-animations.js`, embedded like `animation-values.js`): `sync(el)` reads the element's computed `animation-*` and `display`, keeps the `CSSAnimation` of a name that stays, retimes it (`updateTiming`, `animation-play-state` pauses and plays), starts new ones from `ak.keyframes(name)` (keyframes merged by offset; per-keyframe `animation-timing-function` is the keyframe's easing, the element's is the default and the easing of the implicit 0%/100% keyframes, `KeyframeEffect._implicitEasing`), and cancels the rest (also for `display: none` and a disconnected element). Values apply through P10.47's fill machinery, so `getComputedStyle` shows them. `sync` runs when `getComputedStyle` reads an element, in `getAnimations()`, and every 16 ms for the elements that have a *running* CSS animation (the transitions' rule): no timer when none runs, and only those elements are restyled.
  - Events (`eventsOf`, the spec's phase table): `animationstart`/`animationiteration`/`animationend`/`animationcancel` with their elapsed times, decided one task after a change (a change and its undo in one script send nothing); a timer at each iteration boundary while running forwards.
