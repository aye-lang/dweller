- one real loss since that baseline, 6 subtests: `animation/transform-interpolation-007.html` 42/42 -> 36/42 (area 2834/5428, 52.2%). The Q6.1 merge fix 5f00c74 kept `transition-behavior: allow-discrete` away from the transform properties (`allowsDiscrete` returned false for `css.isTransformPart(p)`), so a transition between a singular and an invertible matrix did not start at all and the computed value was the end value at once.
- design: `browser/animation/allows-discrete.aye` drops the `isTransformPart` exclusion. A transform pair that cannot interpolate now starts a transition under `allow-discrete` and `transitionMix` flips it at 50%, as for the layer properties (css-transitions-2, `transition-behavior`). Without `allow-discrete` nothing changes: no transition starts.
- references: https://drafts.csswg.org/css-transitions-2/#transition-behavior-property ; https://drafts.csswg.org/css-transforms-1/#matrix-interpolation . No Chromium file read.
