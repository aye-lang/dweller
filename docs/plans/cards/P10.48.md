# P10.48: CSS property ids come from the property table

- goal: adding a longhand is one line in one table (`PROPERTIES`, `browser/css/css.aye`: name, inherited, kind, keywords, initial value); two branches that each add one merge with at most an adjacent-line conflict and no renumbering.
- cause: every CSS card hand-numbered its ids in `css.aye` (`BORDER_COLLAPSE = 135`, ...) and bumped `NPROPS` and the `[N]Property` length, so every pair of CSS branches collided at merge (PR #128 vs main, the #141 chain, #171).
- design: a property's id is its position in `PROPERTIES`. `browser/tools/gen_property_ids.py` reads the names in table order and writes `browser/css/property-ids.aye` (checked in): `NPROPS` and one `pub let` per longhand, named after the property in upper case with `-` as `_` and a leading `-` dropped; three keep their old names (`top` is `INSET_TOP`, the `-webkit-border-*-spacing` pair are `BORDER_SPACING_H`/`_V`). `PROPERTIES` is `[NPROPS]Property`, so a table line without a regenerated file is a compile error (E0045), and CI runs the generator with `--check`. Ids, and so every iteration order (cascade, `getComputedStyle`, style dumps), are unchanged: the generated values equal the old constants (the 24 longhands that had none, such as `margin-right`, gain one). Aye has no compile-time loops (top-level `let` folds only single-`return` calls), so the ids cannot be computed from the table inside Aye. New properties go at the end of the table: ranges in `paintOnly` and side loops (`MARGIN_TOP + i`) rely on the order. Merging p10-46b-css-grid: `grid-auto-columns`/`-rows`/`-flow` moved from 140–142 to 147–149, after train-1's text decoration longhands.
- files: `browser/css/css.aye` (constants removed, `[NPROPS]Property`), `browser/css/property-ids.aye` (generated), `browser/tools/gen_property_ids.py`, `.github/workflows/ci.yml`, `docs/browser.md` (B2: how to add a longhand).
- reference: chromium `third_party/blink/renderer/core/css/css_properties.json5` and `build/scripts/make_css_property_names.py` (CSSPropertyID generated from one ordered table); algorithm only.
- verify: `python3 browser/tools/gen_property_ids.py --check`; `check_taste.py`, `check_layers.py` → 0; `aye test browser` → 0; `cargo test --release --test browser -- style_fixtures layout_fixtures jsdom_fixtures errors` → 0; `-- window_ paint screenshot` → 0 except `window_webgl`/`webgl_screenshot` (no ANGLE here). No golden changed.
