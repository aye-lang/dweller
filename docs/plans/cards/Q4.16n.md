# Q4.16n: ImageCache finds entries by a hash map, and a fill skips images whose URL did not change

- goal: zol spent ~2145 ms per 10 s of scroll in `fillImagesWith` (Q4.21 cost 3): every layout resolved each image element's URL again and looked it up by linear scans of `ImageCache.entries` (`known`, `bitmapOf`, `pictureOf`, in `prefetchImages` and `loadElementImage`). Expected zol −1800 ms per 10 s.
- change (`browser/engine/`): `ImageCache.by_href` (`std.map.StrMap`) maps a URL to its first entry, `CachedImage.same_href` chains the entries of the same URL with another mode or credentials (`find-image-entry.aye`, `add-image-entry.aye`); `known`, `pictureOf` and `bitmapOf` use it. `loadElementImage` remembers, per element (`ImageCache.shown`, `std.map.HashMap(NodeId, …)`), the fingerprint of what it showed: base URL, chosen URL, density, `crossorigin`, `referrerpolicy` (`image-fingerprint.aye`, `remember-shown.aye`, `forget-shown.aye`). `fillImagesWith` and `prefetchImages` skip an element whose fingerprint is the same and that still has its bitmap (`shown-unchanged.aye`). An element with no bitmap yet (a background load, a broken image) is tried again as before.
- method: the Q4.21 method. Base = Q4.21's main build (c0231194, aye 5180d0c, `browser/build.sh` safe); new = this branch, `browser/build.sh` safe with aye 5180d0c (`wt-aye-16n`). Timing run: `target/dweller URL --frames 50 --events "3 × frame, 40 × wheel:-3 frame" --state`, `DWELLER_REPLAY=target/sites/zol`, `SDL_VIDEODRIVER=dummy`, `DWELLER_TIMING=1`. `sample PID 8` from 4 s into the same run. W7: `scripts/capped.sh python3 browser/tools/window_perf.py report --replay --site zol --binary …`, 3 runs, interleaved base, new, base, new, base, new; bbc once each. Load 4.5 at the start of the series (another agent's builds and benchmarks queued in `capped.sh`), 2.7 at the end; M2 Pro.
