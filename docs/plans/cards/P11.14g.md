# P11.14g: worker scripts load through the page's network; OffscreenCanvas in workers (not started)

- goal: (1) worker scripts, `importScripts` and module-worker imports load over http(s) through the page's network loader (cache, site archives, same-origin rule for the worker script), plus `blob:` and `data:`; (2) `OffscreenCanvas` in the worker scope (per-Interp bitmap table, 2D, then WebGL with a context current on the worker thread); (3) `transferControlToOffscreen`, transfer through `postMessage`, `commit()`/rAF presenting to the placeholder.
- design:
  - The `net` module is single-threaded (session, cache, loader and libcurl multi are globals driven by the main thread), so the worker thread does not fetch over the network itself: it asks the page.
  - Worker side: `loadBytes(it, href, kind)` keeps `net.fetchLocal` for `file:` and `data:`; other schemes go to `fetchThroughPage`, which posts a `FETCH` (importScripts, module imports) or `FETCH_SAME_ORIGIN` (the worker script) message with the URL on the outbox and blocks in `waitAnswer` on the link's new `answers` list until the page answers or the worker is stopped. An answer is a sealed message whose one buffer is the body; no buffer means a network error ("Failed to load a worker script").
  - Page side: `pumpWorkers` delivers the request like any worker message; `__workerDeliver` (`worker-page.js`) answers `blob:` from the blob registry (`h.answer`), refuses a cross-origin worker script (`FETCH_SAME_ORIGIN`, the `same-origin` request mode of the HTML spec), else calls `h.fetch` (`wkFetch`): `net.request` with kind Script and the page as referrer, so the cache, cookies and site archives apply; a non-2xx status is a network error.
  - Module workers: `Interp.module_loader` (a `ModuleLoader` hook, `module-response.aye`) replaces the `local_loads_only` branch; the worker sets it to `workerModuleResponse`, the same local-or-page path.
  - Goals (2) and (3): not started; the P11.14e design stands (per-Interp bitmap table in place of the page `ImageCache`, per-thread EGL `current`, wire.js `{t: 'C', id, w, h}`, frames posted to the placeholder).
- files: `browser/engine/workers/{fetch-through-page,wait-answer,worker-module-response}.aye`, `browser/engine/{wk-fetch,wk-answer,answer-worker}.aye`; wiring in `workers/{link,new-link,free-link,message,load-bytes,scope-load,set-up-worker,run-worker}.aye`, `workers/worker-page.js`, `worker-api.aye`, `js/{interp,module-response}.aye`, `net/net.aye` (`respond` public); test `worker_http` in `tests/browser.rs`.
- reference: https://html.spec.whatwg.org/multipage/workers.html#fetch-a-classic-worker-script, https://html.spec.whatwg.org/multipage/workers.html#importing-scripts-and-libraries; Blink (algorithm only): `core/workers/worker_classic_script_loader.cc`, `core/workers/dedicated_worker.cc`.
