# P10.50: uievents

- goal: WPT `uievents` from 14.0% (25/178 in the table; 29/178 in the baseline run) to its 70% threshold.
- cause: the one-cause clusters of `wpt.py run uievents -j 8` (`/tmp/ui-base.log`):
  - no named access on the window (`target.focus()` with `<div id=target>`: "target is not defined"): 10 files ERROR before any subtest ran (about 25 subtests once they run);
  - no `getModifierState`, no `modifierAltGraph`/`modifierCapsLock` init (23); `InputEvent.isComposing` (2); event constructors' `length` 2, `initKeyboardEvent`/`initCompositionEvent` without arguments not throwing (4); no `TextEvent` illegal constructor or `initTextEvent` (4); no `UIEvent.pseudoTarget` (2);
  - no boundary events: no `pointerover/out/enter/leave` or `mouseover/out/enter/leave` from real input at all, in the window or the `--events` path (`mouseover-at-removing-mousedown-target` 30, `mouseenter-mouseleave-on-drag` 3, `mousemove-across`/`-between`, `mouseover-out`, `reappending` 6, `synthetic-...-removed` 2); `mouseenter`/`mouseleave` composed (1);
  - click not at the nearest common ancestor of the mousedown and mouseup targets (2);
  - no `pageX/Y`, `offsetX/Y`, `x/y`, `layerX/Y` (2);
  - testdriver `send_keys` with WebDriver modifier keys (``...) sent them as text, no modifier state, no `keypress` (11).
- design: `engine/ui-events.js` (embedded by `ui-events-prelude.aye`, run after `DOM_EVENTS_PRELUDE`) puts a named properties object (a Proxy: a child navigable by name gives its `contentWindow`, else the element by id, else `embed/form/img/object` by name) between `Window.prototype` and `EventTarget.prototype`; the JS engine's unqualified global lookup and `typeof` now use `hasPropertyJs` (the proxy `has` trap) instead of `hasProperty`. Same file: `getModifierState`, `pseudoTarget`, constructor lengths, the argument checks, `TextEvent`, the CSSOM View mouse coordinates. The prelude stores `modifierAltGraph`/`modifierCapsLock` and `InputEvent.isComposing`, and makes enter/leave not composed. Boundary events are native and shared by the window and `--events`: `dispatchPointer` (script.aye) calls `crossBoundary` for `pointermove/down/up`; it keeps the hover path (`Script.hover_path`, target to root, elements, shadow-including) and fires `pointerout`, `pointerleave` on the old path's nodes not on the new one, `pointerover`, `pointerenter` from the outermost new node, then the `mouse*` four (`fire-boundary.aye`); disconnected nodes get none, so a removed `mousedown` target gives `mouseover` at its parent before `mouseup`. `pointerdown` remembers its target; `click` goes to the nearest common inclusive ancestor (`press-release-target.aye`). `--events` keys: `feed-key.aye` holds modifier state (`modifier-bit.aye`), passes it with `keydown/keyup` and fires `keypress` for a printable key or Enter without Ctrl/Alt/Meta; `dom-key.aye` names the modifiers; the testdriver vendor maps the WebDriver modifier code points and holds modifiers until the end of `send_keys`.
- files: `browser/engine/` (`ui-events.js`, `ui-events-prelude.aye`, `cross-boundary.aye`, `fire-boundary.aye`, `on-path.aye`, `hover-path.aye`, `press-release-target.aye`, `modifier-bit.aye`; wiring in `script.aye`, `prelude.aye`, `feed-key.aye`, `dom-key.aye`), `browser/js/interp.aye`, `browser/js/vm-type-of-global.aye`, `browser/tools/wpt/testdriver-vendor.js`, `browser/tests/jsdom/iframes.tree`, `browser/tools/conformance/history.csv` (a duplicated header row from a merge broke `conformance.py table`).
