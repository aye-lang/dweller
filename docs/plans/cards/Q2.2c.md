# Q2.2c: all queued fds read, renderer settings passed, damaged rects only

- goal: the three items Q2.2b left for the renderer's frames. (1) Fast repeated resizes never lose buffers: the renderer reads every queued message and every fd sent with it. (2) The renderer gets the window's font choice and script setting, so a page with scripts looks the same through the renderer as in the window's process. (3) A frame carries only its damaged rects: the renderer draws only those into the free buffer (the rest copied forward from its previous frame), and the window updates only those rects.
- design:
  - `ipc/recvFds`: after the blocking `recvmsg`, it keeps reading (`MSG_DONTWAIT`) into the rest of the buffer until the socket has nothing more or the buffer is full, with a 512-byte control buffer per read; `takeRights` walks every `cmsghdr` in it (`CMSG_ALIGN`: 4 on macOS, 8 on Linux), not only the first. Linux ends a stream read at the first message that carries fds, so two `resize`s need two reads; both now happen in one `recvFds`.
  - settings: the browser spawns the renderer as `dweller --renderer FD --font fixed|system [--no-js]` (`fixed` when the window paints with the fixed font, `--no-js` when the window's scripting is off). `serve` sets scripting, the real clock and the canvas font as `ui/window.aye` does. They are spawn arguments, not a message: the browser chose them, the renderer trusts them; the browser's frame checks are unchanged.
  - the renderer's loop: `poll` on the socket with the page's next timer as the timeout (`timerWait`, `waitReadable`); on a timeout `runTimers` runs the due timers and paints when they ran. `ipc.PollFd` / `ipc.poll` are now declared once in `ipc` (the window's `socket.aye` and `spaces.aye` import them), as C allows one declaration.
  - renderer damage (`paintFrame`, `frameDamage`, `drawDamage`, `putDamage`): the renderer keeps the signatures of the frame it sent last (`drawn`), its background and which buffer (`sent`). The new frame's damage is `paint.diff` of the signatures plus `spreadLayers`, as the window's `drawPage`; whole after new buffers or a new background. `drawDamage` paints straight into the shared buffer (a `paint.Canvas` over the mapping, no canvas copy): it copies the previous frame forward, then for each rect fills the background and renders clipped to it. No damage, no frame. The `frame` message carries the rects (`x0 y0 x1 y1`), empty when whole.
  - window (`showTabFrame`, `addTabDamage`, `copyTabFrame`): a shown frame adds its rects to `tp.damage` (or sets `tp.whole`); the poll asks for a repaint (`ui.repaint`, not `ui.dirty`, so no whole window draw). `drawPage` adds those rects to the page's damage and, after drawing each rect of its own page, copies that rect from the shown buffer into the page's pixels (through the scroll ring), so only those rects are uploaded and presented. The page area is no longer drawn whole for a tab frame (`pageOverlays`), and `drawTabFrame` (a whole copy into the window canvas) is gone. A `frame` message alone does not mark the window dirty (`takeMessages`).
  - test hook: the `--state` line is `renderer-frame W H damage [x0 y0 x1 y1 ...]` (the last frame's rects, none when whole).
- Chromium read (idea only): `mojo/core/channel_posix.cc` (reads until the socket would block, and takes every handle of every control message, `SocketRecvmsg` walking `CMSG_NXTHDR`); `components/viz/service/display/display.cc` (a frame's damage rect decides what is drawn and swapped, the rest of the buffer is kept). Dweller takes: read until empty and walk all cmsgs; the frame's damage rects bound both the renderer's drawing and the window's update.
- files: `browser/ipc/{recv-fds,take-rights}.aye`, new `browser/ipc/{poll,recv-fds_test}.aye`; `browser/renderer/{serve,serve-on,tab-renderer,take-buffers,paint-frame}.aye`, new `browser/renderer/{frame-damage,draw-damage,put-damage,run-timers,timer-wait,wait-readable}.aye`; `browser/main.aye`; `browser/ui/{start-tab-process,poll-tab-processes,tab-process,end-tab-process,show-tab-frame,take-messages,write-tab-process,pagedraw,window,socket,spaces}.aye`, new `browser/ui/{add-tab-damage,copy-tab-frame}.aye`, removed `browser/ui/draw-tab-frame.aye`; new `browser/tests/ui/renderer_damage.html`; `tests/browser.rs` (`window_renderer_frames`); `docs/process-model.md` (the lifecycle row: scripts run, settings as spawn arguments).
