# P10.51f: focus state restyles locally

- goal: (1) `:focus`, `:focus-within`, `:focus-visible` go through P10.51e's local pointer-state invalidation instead of `STATE_CHANGED` and a full restyle: a focus move restyles only the elements whose state changes; (2) narrow descendant/sibling invalidation by the features of the compounds (Blink invalidation sets); (3) hover in iframes restyles locally in the frame; (4) `Transitions.kept` stops growing. P10.51e's "left" list.
- design:
  - `css.FOCUS_CHANGED` (`what` 4; `nameKey` now clear of 0..4) is a pointer-state change (`isPointerState`); `simpleKeys` gives `:focus`/`:focus-within`/`:focus-visible` its key, so the deep/shallow and sibling rules of P10.51e apply. `RestyleDeps.focus` (`looksAtFocus`, UA and author sheets) gates it in `seesState`.
  - `setFocus` and the new `setFocusVisible` (used where the window and the agent flip `focus_visible`) call `noteFocus`: the elements that left the old focus chain or entered the new one are noted (`notePointerState`, below their common ancestor); a `focus_visible` flip on the same element notes only it. Without a script it moves `Controls.pointer_styled`, which the style inputs hash.
  - `controlInputs` no longer hashes the focus and `focus_visible` (they are noted now), and skips controls that still mirror their markup (`isDefaultControl`: value equal to the default, no checked/selected/custom changes): focusing a field creates its control entry, which used to unshare the layout on every first focus.
  - `restyleRoots` takes a subject-only change before asking for the parent element, so a change noted at `html` (a chain from or to no focus) stays local instead of failing the restyle.
  - Window: Tab and blur lay out (`ui.relayout`) instead of `restyled` (a full restyle); a click that moved the focus to another element no longer blurs it (the blur test now checks that the focus is still the old element).
- files: `browser/css/` (`looks-at-focus.aye`, `is-default-control.aye`; `sees-state.aye`, `is-pointer-state.aye`); `browser/engine/` (`note-focus.aye`, `set-focus-visible.aye`); wiring in `css/invalidation.aye`, `css/inputs.aye`, `engine/forms.aye`, `engine/geometry.aye`, `ui/forms.aye`, `agent/actions.aye`. Tests: `browser/tests/ui/focus_local.html` (20 inputs, `form:focus-within`, `input:focus-visible`); `tests/browser.rs` `window_focus_local`.
- reference: blink `core/css/invalidation/rule_invalidation_data.cc` (pseudo-class features), `core/dom/element.cc` (FocusStateChanged, FocusWithinStateChanged); algorithm only. https://drafts.csswg.org/selectors-4/#the-focus-pseudo, https://drafts.csswg.org/selectors-4/#the-focus-within-pseudo, https://drafts.csswg.org/selectors-4/#the-focus-visible-pseudo.
